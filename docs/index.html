触感空间：手机屏幕就是最方便的触感记录仪

想让陪伴模型「感觉」到你，除了做外接设备、连接传感器，你手里的手机也是很方便的触感记录仪：用了几根手指、碰在哪里、力度轻重、速度快慢，它都能记录下来，而且离你的手最近。剩下要做的有三件事：让屏幕在你的手指下有反馈（画面变形、震动），把记录下来的触摸翻译成模型读得懂的身体感觉，再写进你发出的消息里。

下面每一节先讲思路，再按平台给代码。代码是从我们自己的实现里整理出来的，标了「实测」的跑过；标「未实测」的是照官方 API 写的思路代码，拿去用要自己试。接到我们自己聊天前端的那部分接口没有放出来，换成了通用写法。

先摸摸看

这块触摸板用的就是下面「翻译」那一节的规则。你可以在上面轻点、按住、滑动、画圈，或者用两根手指张开、合拢；停手两秒后，它会把这批触摸翻译成一段话，也就是模型最终会收到的内容。

还没摸
在这里摸（手机上用手指，电脑上用鼠标或触控板）
停手两秒后，翻译会出现在这里。
在安卓 Chrome 上还会跟着震动；iPhone 的网页不支持震动。

记下每一笔

一根手指从按下到抬起是一笔，期间不停地记位置、时间、轻重。几根手指同时按着就是同时有几笔。所有手指离开、两秒内没再摸，这一批就记完了，交给翻译。

轻重最麻烦：现在的 iPhone 没有压感（3D Touch 的硬件已经拆了），只能根据手指贴在屏幕上的面积来估算。轻轻点大约是半径 12–20pt，按实了能到 40pt 上下，换算成 0–1。档位粗，但够分出四档。

平台位置和时间轻重

安卓原生onTouchEvent，多指用 getPointerId，中间点用 getHistoricalX/YgetPressure()（很多机型给的也是面积换算的值）、getTouchMajor() 接触面积，按机型选

import Foundation
import CoreGraphics

/// 触感模块的记录账：一批还没发出去的触摸（笔），发送时整批换成一段感觉式描述。
///
/// - 触摸只来自触感空间里的那块表面。
/// - 位置相对「它」（触感空间里的整块聊天屏幕，`form` = 画布整块）。
/// - 什么时候发由宿主决定（按发送时调用 `TouchSpace.takeForSending()` 取走这一批）；这里只记账。

// MARK: - 数据

struct TouchSample {
    /// 表面视图里的坐标（点，左上原点）。
    let point: CGPoint
    /// 系统开机以来的秒数（`UITouch.timestamp` / `NSEvent.timestamp` 同一时基）。
    let time: TimeInterval
    /// 0…1，怎么来的见 `TouchPressureSource`。
    let pressure: CGFloat
    /// 原始读数：接触半径（pt）/ 力 / 触控板压力。
    let raw: CGFloat
}

struct TouchStroke: Identifiable {
    let id = UUID()
    var samples: [TouchSample]
    var ended = false
    var endedAt: TimeInterval?
    /// 实时触摸：上一次发送时这根手指还按着，这一笔是接着那一下的（描述写「接着……」，不当成新的一点）。
    var continued = false

    var start: TimeInterval { samples.first!.time }
    var end: TimeInterval { endedAt ?? samples.last!.time }
}

enum TouchPressureSource: Equatable {
    /// 3D Touch / Apple Pencil 的力。
    case force
    /// 没有压感硬件：按接触半径估。
    case contactArea
    /// Mac 的鼠标 / Force Touch 触控板。
    case trackpad
}

/// 一次带走的触摸：一段描述，已包好 `<touch>` 标签（气泡的消息装饰靠标签把它收成一只手）。
public struct TouchPacket {
    let text: String

    static let openTag = "<touch"
    static let closeTag = "</touch>"

    /// 把一条用户消息拆成「触摸描述」与正文。没有触摸段时 `touch` 为 nil、正文原样。
    public static func split(_ text: String) -> (touch: String?, strokes: Int, rest: String) {
        guard text.hasPrefix(openTag), let close = text.range(of: closeTag) else { return (nil, 0, text) }
        let block = String(text[..<close.upperBound])
        let rest = String(text[close.upperBound...]).trimmingCharacters(in: .whitespacesAndNewlines)
        var strokes = 0
        if let attr = block.range(of: "strokes=\""),
           let quote = block[attr.upperBound...].firstIndex(of: "\""),
           let parsed = Int(block[attr.upperBound..<quote]) {
            strokes = parsed
        }
        let lines = block.split(separator: "\n", omittingEmptySubsequences: false)
        let body = lines.dropFirst().dropLast().joined(separator: "\n")
        return (body, strokes, rest)
    }
}

@MainActor
final class TouchStore: ObservableObject {
    /// 上次发送以来记下的笔数。
    @Published private(set) var pendingCount = 0

    /// 「你」= 画布整块（描述里的位置相对它）。画布尺寸变了时由空间填。
    var form: CGRect = .zero
    /// 位置用哪套说法（屏幕 / 身体，调参面板里选）。由空间按手感参数填。
    var placeMap: TouchPlaceMap = .screen

    private var strokes: [TouchStroke] = []
    /// 正在进行的触摸 → `strokes` 里的下标。
    private var active: [AnyHashable: Int] = [:]

    var hasPending: Bool { pendingCount > 0 }
    /// 还有手指按着。
    var isTouching: Bool { !active.isEmpty }

    private static let sampleCap = 600
    private static let strokeCap = 200

    func began(_ key: AnyHashable, _ sample: TouchSample, source _: TouchPressureSource) {
        strokes.append(TouchStroke(samples: [sample]))
        if strokes.count > Self.strokeCap {
            let drop = strokes.count - Self.strokeCap
            strokes.removeFirst(drop)
            active = active.compactMapValues { $0 >= drop ? $0 - drop : nil }
        }
        active[key] = strokes.count - 1
        pendingCount = strokes.count
    }

    func moved(_ key: AnyHashable, _ samples: [TouchSample]) {
        guard let index = active[key] else { return }
        defer { pendingCount = strokes.count }
        for sample in samples {
            let last = strokes[index].samples.last!
            if hypot(sample.point.x - last.point.x, sample.point.y - last.point.y) < 1.5,
               abs(sample.pressure - last.pressure) < 0.03 { continue }
            if strokes[index].samples.count < Self.sampleCap { strokes[index].samples.append(sample) }
        }
    }

    func ended(_ key: AnyHashable, at time: TimeInterval) {
        guard let index = active.removeValue(forKey: key) else { return }
        strokes[index].ended = true
        strokes[index].endedAt = time
        pendingCount = strokes.count
    }

    /// 清掉这一批（长按胶囊）。
    func discard() {
        strokes = []
        active = [:]
        pendingCount = 0
    }

    /// 把此刻按着的那几笔从账上抹掉（三指长按打开调参面板时：那三根手指不是在摸「它」）。
    func dropActive() {
        let gone = Set(active.values)
        strokes = strokes.enumerated().filter { !gone.contains($0.offset) }.map(\.element)
        active = [:]
        pendingCount = strokes.count
    }

    /// 发送时调：把这一批整个带走。还按着的那几笔截到此刻带走（描述里写「还没松手」），
    /// 账上从最后一个采样接着记（实时触摸「边摸边发」时手指不用抬起来）。没有就返回 nil。
    func takePacket() -> TouchPacket? {
        guard !strokes.isEmpty else { return nil }
        let now = ProcessInfo.processInfo.systemUptime
        var batch = strokes
        let holding = active
        // 还按着的那几笔截到此刻：一直按着不动时没有新采样，不截的话时长会算成 0。
        for index in holding.values { batch[index].endedAt = now }
        strokes = []
        active = [:]
        for (key, index) in holding {
            // 从截断这一刻接着记（同一个位置和轻重，时间换成此刻）：时长从这次发送算起。
            let last = batch[index].samples.last!
            var next = TouchStroke(samples: [TouchSample(point: last.point, time: now, pressure: last.pressure, raw: last.raw)])
            next.continued = true
            strokes.append(next)
            active[key] = strokes.count - 1
        }
        // 接着记的那几笔也算待发：一直按着不动也会在下一次发送时写成「接着按了……，还没松手」。
        // 普通用法（摸完放进输入框）发送时手指早就抬起来了，这里是 0。
        pendingCount = strokes.count
        return TouchPacket(text: TouchSummary.text(batch, form: TouchForm(rect: form, map: placeMap), sentAt: now))
    }
}

  const MAX_DROPS = 40, MAX_F = 5;

  // ---------- 着色器：画面是一张纹理，按手指算每个像素该从哪里取色 ----------
  const VS = 'attribute vec2 a; void main(){ gl_Position = vec4(a,0.,1.); }';
  const FS = `
precision highp float;
uniform sampler2D uTex; uniform vec2 uRes; uniform float uTime, uMode, uDpr, uAmp;
uniform vec4 uDrops[${MAX_DROPS}];   // 水纹：x, y, 起始时刻, 强度
uniform vec4 uF[${MAX_F}];           // 皮肤：x, y, 深度, 暖
uniform vec2 uO[${MAX_F}];           // 皮肤：被手指拖着走的位移
uniform vec3 uWarm;
void main(){
  vec2 p = gl_FragCoord.xy, s = p; vec3 add = vec3(0.); float mul = 1., warm = 0.;
  if (uMode < .5) {
    // 水纹：每滴起一两道圈往外走，150pt/秒，1.6 秒散完
    vec2 disp = vec2(0.); float light = 0.;
    for (int i = 0; i < ${MAX_DROPS}; i++) {
      vec4 d = uDrops[i]; float age = uTime - d.z;
      if (d.w <= 0. || age < 0. || age > 1.6) continue;
      float lam = (22. + 18. * age) * uDpr, w = lam * .55;
      vec2 v = p - d.xy; float r = length(v) + .001; float x = r - age * 150. * uDpr;
      float env = exp(-x * x / (w * w)) * exp(-age * 2.2) * d.w / (1. + r / (140. * uDpr));
      env *= smoothstep(0., 16. * uDpr, r);
      float ph = x * 6.2831 / lam; disp += v / r * sin(ph) * env; light += cos(ph) * env;
    }
    s = p - disp * 10. * uDpr * uAmp; add = vec3(light * .06 * uAmp);
  } else {
    // 皮肤：手指处陷下去一小块，被拖着走，按久了透出暖色
    vec2 L = normalize(vec2(-.55, .8));
    for (int i = 0; i < ${MAX_F}; i++) {
      vec4 f = uF[i];
      if (abs(f.z) < 1e-4 && dot(uO[i], uO[i]) < 1e-4) continue;
      float R = (34. + 8. * f.w) * uDpr; vec2 v = p - f.xy; float r2 = dot(v, v);
      float fa = exp(-r2 / (R * R)), fb = exp(-r2 / (R * R * 1.6));
      s += v * f.z * .85 * fa * uAmp - uO[i] * fb * uAmp;
      vec2 g = v / R * 2. * f.z * fa;
      add += vec3(dot(g, L) * .16 * uAmp); mul *= 1. - .18 * max(f.z, 0.) * fa; warm += f.w * max(f.z, 0.) * fa;
    }
  }
  vec3 col = texture2D(uTex, clamp(s / uRes, vec2(0.), vec2(1.))).rgb * mul + add;
  gl_FragColor = vec4(mix(col, uWarm, clamp(warm * .16, 0., .32)), 1.);
}`;

  const ramp = (x, a, b) => { const t = Math.min(1, Math.max(0, (x - a) / (b - a))); return t * t * (3 - 2 * t); };
  const settled = s => Math.abs(s.depth) < .002 && Math.abs(s.dv) < .01 && Math.hypot(s.ox, s.oy) < .05 && Math.hypot(s.ovx, s.ovy) < .1 && s.warm < .01;

      ctx.globalAlpha = 1;
    }
    function redraw() {
      const c = colors();
      ctx.setTransform(dpr, 0, 0, dpr, 0, 0);
      if (typeof background === 'function') background(ctx, W, H);
      else if (background) ctx.drawImage(background, 0, 0, W, H);
      else drawPaper(c);
      if (!gl) return;

      gl.uniform3fv(U.uWarm, rgb(c.warm));
      wake();
    }
    function resize() {

      dpr = Math.min(devicePixelRatio || 1, 2); W = Math.max(1, r.width); H = Math.max(1, r.height);
      for (const c of [canvas, src]) { c.width = Math.round(W * dpr); c.height = Math.round(H * dpr); }
      if (gl) { gl.viewport(0, 0, canvas.width, canvas.height); gl.uniform2f(U.uRes, canvas.width, canvas.height); gl.uniform1f(U.uDpr, dpr); }
      redraw();
    }

    function emitDrop(x, y, amp) { const d = { x, y, t: now(), amp };
      if (drops.length < MAX_DROPS) drops.push(d); else { drops[dropHead] = d; dropHead = (dropHead + 1) % MAX_DROPS; } }
    function newSlot(id, x, y) {
      let s = slots.find(s => !s.active && settled(s));
      if (!s) { if (slots.length < MAX_F) { s = { depth: 0, dv: 0, warm: 0 }; slots.push(s); } else s = slots.reduce((a, b) => (a.downAt < b.downAt ? a : b)); }
      Object.assign(s, { id, active: true, downAt: now(), fx: x, fy: y, cx: x, cy: y, gx: x, gy: y, gvx: 0, gvy: 0, ox: 0, oy: 0, ovx: 0, ovy: 0, hold: 0 });
      return s;
    }
    function stepSlot(s, h) {
      if (s.active) s.hold += h;
      const hr = ramp(s.hold, .35, 2.6);
      if (s.active) {
        s.cx = s.fx; s.cy = s.fy;
        const k = 40, c = 2 * Math.sqrt(k);   // 皮肤被手指黏着拖
        s.gvx += (k * (s.fx - s.gx) - c * s.gvx) * h; s.gvy += (k * (s.fy - s.gy) - c * s.gvy) * h; s.gx += s.gvx * h; s.gy += s.gvy * h;
        const dx = s.fx - s.gx, dy = s.fy - s.gy, L = Math.hypot(dx, dy), M = 24, f = L > 0 ? M * Math.tanh(L / M) / L : 0;
        s.ox = dx * f; s.oy = dy * f; s.ovx = s.ovy = 0; s.warm += (hr - s.warm) * Math.min(1, h * 1.5);
      } else {
        const k = 110, c = 7;                 // 松手：欠阻尼弹回、晃两下
        s.ovx += (-k * s.ox - c * s.ovx) * h; s.ovy += (-k * s.oy - c * s.ovy) * h; s.ox += s.ovx * h; s.oy += s.ovy * h;
        s.warm -= s.warm * Math.min(1, h * .45);
      }
      const target = s.active ? .55 + .45 * hr : 0;
      s.dv += (220 * (target - s.depth) - 15 * s.dv) * h; s.depth += s.dv * h;
    }

    // ---------- 渲染：只在有东西在动时跑，静下来一帧都不画 ----------
    let running = false, last = 0, alive = true;
    const dropArr = new Float32Array(MAX_DROPS * 4), fArr = new Float32Array(MAX_F * 4), oArr = new Float32Array(MAX_F * 2);
    const busy = () => fingers.size > 0 || (mode === 0 ? drops.some(d => now() - d.t < 1.6) : slots.some(s => s.active || !settled(s)));
    function wake() { if (!running && gl && alive) { running = true; last = performance.now(); requestAnimationFrame(frame); } }
    function frame(ts) {
      if (!alive) { running = false; return; }
      const dt = Math.min((ts - last) / 1000, 1 / 20); last = ts;
      const steps = Math.max(1, Math.round(dt * 240));
      if (mode === 1) for (let i = 0; i < steps; i++) for (const s of slots) stepSlot(s, dt / steps);
      draw();
      if (busy()) requestAnimationFrame(frame); else { running = false; draw(); }
    }
    function draw() {
      dropArr.fill(0); fArr.fill(0); oArr.fill(0);
      drops.forEach((d, i) => dropArr.set([d.x * dpr, (H - d.y) * dpr, d.t, d.amp], i * 4));
      slots.forEach((s, i) => { fArr.set([s.cx * dpr, (H - s.cy) * dpr, s.depth, s.warm], i * 4); oArr.set([s.ox * dpr, -s.oy * dpr], i * 2); });
      gl.uniform1f(U.uTime, now()); gl.uniform1f(U.uMode, mode); gl.uniform1f(U.uAmp, reduced ? .5 : 1);
      gl.uniform4fv(U.uDrops, dropArr); gl.uniform4fv(U.uF, fArr); gl.uniform2fv(U.uO, oArr);
      gl.drawArrays(gl.TRIANGLE_STRIP, 0, 4);
    }

    // ---------- 记下每一笔：一根手指从按下到抬起是一笔 ----------
    let strokes = [], timer = null;
    const at = e => { const r = canvas.getBoundingClientRect(); return [e.clientX - r.left, e.clientY - r.top]; };
    function flush() {

      const batch = strokes; strokes = [];
      const text = T.describe(batch, { w: W, h: H }, map);
      if (opt.onBatch) opt.onBatch(text, batch);
      return text;
    }

      strokes.push(stroke);
      const f = { stroke, lx: x, ly: y, lt: now(), ex: x, ey: y, travel: 0 };
      fingers.set(e.pointerId, f);
      if (mode === 0) emitDrop(x, y, 1); else f.slot = newSlot(e.pointerId, x, y);
      buzz(Math.round(8 + 25 * p));                         // 按下那一下：越重越长
      if (opt.onStart) opt.onStart(strokes.length, pressureSource(e));
      wake();

      const step = Math.hypot(x - f.lx, y - f.ly), sp = step / dt;
      f.lx = x; f.ly = y; f.lt = t; f.travel += step;
      const lastS = f.stroke.samples[f.stroke.samples.length - 1];
      if (Math.hypot(x - lastS.x, y - lastS.y) >= 1.5) { f.stroke.samples.push({ x, y, t: e.timeStamp / 1000, p }); f.stroke.end = e.timeStamp / 1000; }

      wake();
    };
    canvas.style.touchAction = 'none';   // 不让浏览器拿去滚动、缩放

    resize();

      },
    };

data class Sample(val x: Float, val y: Float, val t: Double, val p: Float)
class Stroke(val samples: MutableList<Sample>, var ended: Boolean = false)

private val strokes = mutableListOf<Stroke>()
private val active = mutableMapOf<Int, Stroke>()          // pointerId → 这根手指的一笔

private fun pressureOf(e: MotionEvent, i: Int): Float {
    // 有的机型 getPressure 是真压力，有的是按面积换算的；也可以用接触椭圆的长轴 touchMajor（像素）自己换算
    val major = e.getTouchMajor(i) / resources.displayMetrics.density   // 换成 dp
    val byArea = ((major / 2 - 12) / 32).coerceIn(0f, 1f)
    return maxOf(e.getPressure(i).coerceIn(0f, 1f), byArea)
}

override fun onTouchEvent(e: MotionEvent): Boolean {
    val t = e.eventTime / 1000.0
    when (e.actionMasked) {
        MotionEvent.ACTION_DOWN, MotionEvent.ACTION_POINTER_DOWN -> {
            val i = e.actionIndex
            val s = Stroke(mutableListOf(Sample(e.getX(i), e.getY(i), t, pressureOf(e, i))))
            strokes += s; active[e.getPointerId(i)] = s
        }
        MotionEvent.ACTION_MOVE -> for (i in 0 until e.pointerCount) {
            val s = active[e.getPointerId(i)] ?: continue
            // 一帧里攒下的中间点（对应 iOS 的合并触摸）
            for (h in 0 until e.historySize)
                s.samples += Sample(e.getHistoricalX(i, h), e.getHistoricalY(i, h), e.getHistoricalEventTime(h) / 1000.0, pressureOf(e, i))
            s.samples += Sample(e.getX(i), e.getY(i), t, pressureOf(e, i))
        }
        MotionEvent.ACTION_UP, MotionEvent.ACTION_POINTER_UP, MotionEvent.ACTION_CANCEL -> {
            val i = e.actionIndex
            active.remove(e.getPointerId(i))?.ended = true
            // 停手两秒自动发：两秒没再摸就翻译这一批（规则同 translate.js）。
            // 和你的话一起发：这里不翻译，触摸一直攒着，用户点「确认」或「发送」时再翻译。
            if (active.isEmpty() && autoSend) scheduleTranslate()
        }
    }
    return true
}

屏幕在你指下变形，是让人觉得「摸到了东西」的关键。做法：进入触感空间那一刻，把聊天页拍成一张图，铺满屏幕，再用一个全屏着色器，根据手指的位置让这张图变形。在手指碰到之前，它看起来和聊天页面一模一样；而且这个方法适用于任何界面，不需要修改聊天页面本身。

  • 省电：只在有东西在动时画；一静下来，画完最后一帧就暂停，一帧都不画。截图和画布最多按 2 倍像素算。
  • 想让回话出现在被摸的画面里：把触感空间放到单独一层（iOS 是单独的窗口），这样随时能重拍下面的聊天页，回话一到就重拍一次。

// SPDX-License-Identifier: PolyForm-Noncommercial-1.0.0
// 触感空间的着色器（全屏滤镜）。
//
// 进空间前截的聊天页是一张纹理，`touch_filter_fragment` 按手指算每个像素该从截图的哪里取色。
// 和 web/touch-surface.js 里的 GLSL 是同一套，常数照搬。与草图的差别只有坐标系：
// 草图用 gl_FragCoord（左下原点、y 向上），这里用 Metal 的片元坐标（左上原点、y 向下），所以
// - 手指、水滴的位置直接传像素坐标，不做 `H - y` 翻转；皮肤的拖拽位移 y 也不取反；
// - 皮肤的光照方向 (-.55, .8) 写成 (-.55, -.8)。
//
// 统一参数 `u` 是一串 float4，下标与 Swift 侧 `TouchFilter.uniforms` 一一对应（改一边必须改另一边）：
//   u[0] = 画布像素宽高、时间（秒）、模式（0 水纹 / 1 皮肤）
//   u[1] = 渲染缩放（草图的 uDpr）、幅度、皮肤范围倍数（调参面板，1 = 出厂）、0
//   u[2] = 画布在截图里的 UV 子矩形：原点 xy、尺寸 zw
//   u[3] = 暖色 rgb；u[4] = 空着
//   u[5 + i]  = 第 i 滴水：x、y（像素）、起始时刻、强度（40 滴）
//   u[45 + i] = 第 i 根手指：x、y（像素）、深度 / 吸力、暖（5 根）
//   u[50 + i] = 第 i 根手指被拖着走的位移 x、y（像素）

#include <metal_stdlib>
using namespace metal;

constant int kTouchFilterDrops = 40;
constant int kTouchFilterFingers = 5;
constant int kTouchFilterDropBase = 5;
constant int kTouchFilterFingerBase = 45;
constant int kTouchFilterOffsetBase = 50;

struct TouchVOut {
    float4 position [[position]];
    float2 uv;
};

vertex TouchVOut touch_vertex(uint vid [[vertex_id]]) {
    // 一个盖满屏幕的大三角形。uv 左上为原点（与 pt 坐标同向）。
    float2 xy = float2(float((vid << 1) & 2), float(vid & 2));
    TouchVOut o;
    o.position = float4(xy * 2.0 - 1.0, 0.0, 1.0);
    o.uv = float2(xy.x, 1.0 - xy.y);
    return o;
}

fragment float4 touch_filter_fragment(TouchVOut in [[stage_in]],
                                           texture2d<float> page [[texture(0)]],
                                           sampler smp [[sampler(0)]],
                                           constant float4 *u [[buffer(0)]]) {
    float2 res = u[0].xy;
    float time = u[0].z, mode = u[0].w;
    float dpr = u[1].x, amp = u[1].y, skinSize = u[1].z;
    float3 warmColor = u[3].rgb;

    float2 p = in.position.xy, s = p;
    float3 add = float3(0.0);
    float mul = 1.0, warm = 0.0;
    if (mode < 0.5) {
        float2 disp = float2(0.0);
        float light = 0.0;
        // 一滴只起一两道圈：包络比波长窄，圈往外走、变宽、变淡。
        for (int i = 0; i < kTouchFilterDrops; i++) {
            float4 d = u[kTouchFilterDropBase + i];
            float age = time - d.z;
            // 缩小过（水纹太大会扫过整块屏幕）：原来圈以 300pt/s 走 2.6 秒、能扫过整块屏幕。
            // 现在 150pt/s、1.6 秒散完、衰减更快、波长更短，圈大约在指尖外一两百 pt 内就淡掉。
            if (d.w <= 0.0 || age < 0.0 || age > 1.6) continue;
            float lam = (22.0 + 18.0 * age) * dpr, w = lam * 0.55;
            float2 v = p - d.xy;
            float r = length(v) + 0.001;
            float x = r - age * 150.0 * dpr;
            float env = exp(-x * x / (w * w)) * exp(-age * 2.2) * d.w / (1.0 + r / (140.0 * dpr));
            env *= smoothstep(0.0, 16.0 * dpr, r);
            float ph = x * 6.2831 / lam;
            disp += v / r * sin(ph) * env;
            light += cos(ph) * env;
        }
        s = p - disp * 10.0 * dpr * amp;
        add = float3(light * 0.06 * amp);
    } else {
        const float2 L = normalize(float2(-0.55, -0.8));
        for (int i = 0; i < kTouchFilterFingers; i++) {
            float4 f = u[kTouchFilterFingerBase + i];
            float2 o = u[kTouchFilterOffsetBase + i].xy;
            if (abs(f.z) < 1e-4 && dot(o, o) < 1e-4) continue;
            // 真机上调小过（变形面积要小一些、跟着手指）：
            // 凹陷 58→34pt（按久了 +18→+8），被拖的那圈 R²×3.2→×1.6（≈104pt→43pt）。
            // 高斯在 2R 处才淡到看不出，所以 34pt 大约是「指腹边上再露出一圈」，不会整块藏在手指底下。
            float R = (34.0 + 8.0 * f.w) * dpr * skinSize;
            float2 v = p - f.xy;
            float r2 = dot(v, v);
            float fa = exp(-r2 / (R * R)), fb = exp(-r2 / (R * R * 1.6));
            s += v * f.z * 0.85 * fa * amp - o * fb * amp;
            float2 g = v / R * 2.0 * f.z * fa;
            add += float3(dot(g, L) * 0.16 * amp);
            mul *= 1.0 - 0.18 * max(f.z, 0.0) * fa;
            warm += f.w * max(f.z, 0.0) * fa;
        }
    }
    float2 uv = clamp(s / res, float2(0.0), float2(1.0));
    uv = u[2].xy + uv * u[2].zw;
    float3 col = page.sample(smp, uv).rgb * mul + add;
    col = mix(col, warmColor, clamp(warm * 0.16, 0.0, 0.32));
    return float4(col, 1.0);
}

        let info = CGImageAlphaInfo.premultipliedFirst.rawValue | CGBitmapInfo.byteOrder32Little.rawValue
        guard let context = CGContext(data: nil, width: width, height: height, bitsPerComponent: 8, bytesPerRow: 0,

            context.translateBy(x: 0, y: content.bounds.height)
            context.scaleBy(x: 1, y: -1)
        }
        content.layer!.render(in: context)
        guard let image = context.makeImage() else { throw Failure.convert }
        return TouchSnapshot(image: image, size: content.bounds.size)
        #endif

/// 滤镜的手指物理：网页草图 `stepSlot` / `pointerdown` / `pointermove` 的逐行移植，常数照搬。
/// 坐标一律是画布里的点（pt，左上原点，y 向下）；草图里传给着色器前做的 y 翻转在这里不需要
/// （Metal 的片元坐标本来就是左上原点）。
///
/// - 水纹：按下落一滴（强度 1），划动每 22pt 落一滴，强度 0.35 + min(速度 / 2200, 0.5)；环形缓冲最多 40 滴，1.6 秒散完。
/// - 皮肤：最多 5 个手指槽，固定子步 1/240 秒推弹簧。
@MainActor
final class TouchFilter {
    static let maxDrops = 40
    static let maxFingers = 5
    static let dropLife: Double = 1.6
    /// 统一参数（一串 float4）的布局，与 `.metal` 里 `kTouchFilter*` 一起改：
    ///   u[0] = 画布像素宽高、时间（秒）、模式
    ///   u[1] = 渲染缩放（草图的 uDpr）、幅度（减弱动态效果时 0.5）、皮肤范围倍数、0
    ///   u[2] = 画布在截图里的 UV 子矩形：原点 xy、尺寸 zw
    ///   u[3] = 暖色 rgb、0；u[4] = 空着（原来是涌向指尖的指尖光）
    ///   u[5 + i]  = 第 i 滴水：x、y（像素）、起始时刻、强度
    ///   u[45 + i] = 第 i 根手指：x、y（像素）、深度 / 吸力、暖
    ///   u[50 + i] = 第 i 根手指（皮肤）被拖着走的位移 x、y（像素）、0、0
    static let dropBase = 5
    static let fingerBase = dropBase + maxDrops
    static let offsetBase = fingerBase + maxFingers
    static let uniformCount = offsetBase + maxFingers

    private struct Drop {
        var x: Double, y: Double, t: Double, amp: Double
    }

    private struct Pointer {
        var x: Double, y: Double
        /// 上一个采样（算速度）。
        var lx: Double, ly: Double, lt: Double
        /// 上一滴落下的位置（水纹：每 22pt 一滴）。
        var ex: Double, ey: Double
        var slot: Int?
        let downAt: Double
        /// 平滑过的速度（pt/s），给抚的震动用（同原来表面的 0.6 / 0.4 平滑）。
        var hapticSpeed: Double = 0
    }

    private struct Slot {
        var key: AnyHashable
        var active = true
        var downAt: Double
        var fx: Double, fy: Double
        var cx: Double, cy: Double
        var gx: Double, gy: Double, gvx = 0.0, gvy = 0.0
        var ox = 0.0, oy = 0.0, ovx = 0.0, ovy = 0.0
        var depth: Double, dv: Double
        var hold = 0.0
        var warm: Double

        var settled: Bool {
            abs(depth) < 0.002 && abs(dv) < 0.01 && hypot(ox, oy) < 0.05 && hypot(ovx, ovy) < 0.1 && warm < 0.01
        }
    }

    private(set) var look: TouchLook
    /// 皮肤范围倍数（调参面板「皮肤范围」，1 = 出厂）。凹陷半径和被拖的位移上限都乘它。
    var skinSize = 1.0
    private var drops: [Drop] = []
    private var dropHead = 0
    private var pointers: [AnyHashable: Pointer] = [:]
    private var slots: [Slot] = []
    private let epoch = CACurrentMediaTime()

    init(look: TouchLook) {
        self.look = look
    }

    private var now: Double { CACurrentMediaTime() - epoch }

    /// 换效果 / 关空间：清掉正在动的波纹和手指（草图点按钮时同样清）。
    func reset(_ look: TouchLook) {
        self.look = look
        drops = []
        dropHead = 0
        pointers = [:]
        slots = []
    }

    /// 有手指按着，或者还有没散完的水滴 / 没回稳的手指槽。
    var isBusy: Bool {
        if !pointers.isEmpty { return true }
        switch look {
        case .ripple:
            let t = now
            return drops.contains { t - $0.t < Self.dropLife }
        case .skin:
            return slots.contains { $0.active || !$0.settled }
        }
    }

    /// 静下来那一刻：散完的水滴、回稳的空槽都拿掉，最后一帧就是原原本本的截图（不留零点几像素的残影）。
    func settle() {
        let t = now
        drops = drops.filter { t - $0.t < Self.dropLife }
        dropHead = 0
        slots = slots.filter { $0.active || !$0.settled }
    }

    // MARK: 手指

    func press(_ key: AnyHashable, at point: CGPoint, time: TimeInterval) {
        let x = Double(point.x), y = Double(point.y)
        var p = Pointer(x: x, y: y, lx: x, ly: y, lt: time, ex: x, ey: y, slot: nil, downAt: now)
        if look == .ripple {
            emitDrop(x, y, 1)
        } else {
            p.slot = newSlot(key, x, y)
        }
        pointers[key] = p
    }

    /// 返回这根手指平滑过的速度（pt/s），给抚的震动用。
    @discardableResult
    func drag(_ key: AnyHashable, to point: CGPoint, time: TimeInterval) -> Float {
        guard var p = pointers[key] else { return 0 }
        let x = Double(point.x), y = Double(point.y)
        let dt = max(time - p.lt, 1.0 / 240)
        let sp = hypot(x - p.lx, y - p.ly) / dt
        p.x = x; p.y = y; p.lx = x; p.ly = y; p.lt = time
        p.hapticSpeed = p.hapticSpeed * 0.6 + sp * 0.4
        if look == .ripple {
            // 划的时候每 22pt 落一滴，划得越快越大。
            if hypot(x - p.ex, y - p.ey) > 22 {
                emitDrop(x, y, 0.35 + min(sp / 2200, 0.5))
                p.ex = x; p.ey = y
            }
        } else if let i = p.slot, slots[i].key == key {
            slots[i].fx = x
            slots[i].fy = y
        }
        pointers[key] = p
        return Float(p.hapticSpeed)
    }

    /// 返回离手那一刻的「长按增益」（0.35 秒起算、2.6 秒爬满，同原来表面的离手触感），给离手的震动用。
    @discardableResult
    func release(_ key: AnyHashable) -> Float {
        guard let p = pointers.removeValue(forKey: key) else { return 0 }
        if let i = p.slot, slots[i].key == key { slots[i].active = false }
        let t = min(max((now - p.downAt - 0.35) / 2.6, 0), 1)
        return Float(1 - pow(1 - t, 3))
    }

    func releaseAll() {
        for key in Array(pointers.keys) { release(key) }
    }

    private func emitDrop(_ x: Double, _ y: Double, _ amp: Double) {
        let d = Drop(x: x, y: y, t: now, amp: amp)
        if drops.count < Self.maxDrops {
            drops.append(d)
        } else {
            drops[dropHead] = d
            dropHead = (dropHead + 1) % Self.maxDrops
        }
    }

    private func newSlot(_ key: AnyHashable, _ x: Double, _ y: Double) -> Int {
        let index: Int
        if let free = slots.firstIndex(where: { !$0.active && $0.settled }) {
            index = free
        } else if slots.count < Self.maxFingers {
            slots.append(Slot(key: key, downAt: now, fx: x, fy: y, cx: x, cy: y, gx: x, gy: y, depth: 0, dv: 0, warm: 0))
            return slots.count - 1
        } else {
            index = slots.indices.min { slots[$0].downAt < slots[$1].downAt }!
        }
        // 草图：深度、深度速度、暖从这个槽原来的值接着走，其余重置。
        let old = slots[index]
        slots[index] = Slot(key: key, downAt: now, fx: x, fy: y, cx: x, cy: y, gx: x, gy: y,
                            depth: old.depth, dv: old.dv, warm: old.warm)
        return index
    }

    // MARK: 推进

    /// 每帧调一次：按固定子步 1/240 秒推手指槽（一帧最多算 1/20 秒，同草图）。
    func advance(dt: Double) {
        guard look != .ripple, !slots.isEmpty else { return }
        let dt = min(dt, 1.0 / 20)
        let steps = max(1, Int((dt * 240).rounded()))
        let h = dt / Double(steps)
        for _ in 0..<steps {
            for i in slots.indices { step(&slots[i], h) }
        }
    }

    private func step(_ s: inout Slot, _ h: Double) {
        if s.active { s.hold += h }
        let hr = ramp(s.hold, 0.35, 2.6)
        switch look {
        case .skin:
            if s.active {
                s.cx = s.fx; s.cy = s.fy
                // 皮肤贴着手指：抓住的那一点追上手指，中间被拉开的就是皮肤被拖着走的量。
                // 收紧（要跟着手指）：k 14→40（追上从约半秒缩到约 0.3 秒），位移上限 46→24pt。
                let k = 40.0, c = 2 * sqrt(k)
                s.gvx += (k * (s.fx - s.gx) - c * s.gvx) * h
                s.gvy += (k * (s.fy - s.gy) - c * s.gvy) * h
                s.gx += s.gvx * h; s.gy += s.gvy * h
                let dx = s.fx - s.gx, dy = s.fy - s.gy, l = hypot(dx, dy), m = 24.0 * skinSize
                let f = l > 0 ? m * tanh(l / m) / l : 0
                s.ox = dx * f; s.oy = dy * f; s.ovx = 0; s.ovy = 0
                s.warm += (hr - s.warm) * min(1, h * 1.5)
            } else {
                // 松手：欠阻尼弹回去，晃两下。
                let k = 110.0, c = 7.0
                s.ovx += (-k * s.ox - c * s.ovx) * h; s.ovy += (-k * s.oy - c * s.ovy) * h
                s.ox += s.ovx * h; s.oy += s.ovy * h
                s.warm -= s.warm * min(1, h * 0.45)
            }
            let target = s.active ? 0.55 + 0.45 * hr : 0
            s.dv += (220 * (target - s.depth) - 15 * s.dv) * h
            s.depth += s.dv * h
        case .ripple:
            break
        }
    }

    private func ramp(_ x: Double, _ a: Double, _ b: Double) -> Double {
        let t = min(1, max(0, (x - a) / (b - a)))
        return t * t * (3 - 2 * t)
    }

    // MARK: 统一参数

    /// - Parameters:
    ///   - scale: 画布像素 / pt（草图的 uDpr；iOS 封顶 2）。
    ///   - uvRect: 画布在截图里的 UV 子矩形（0…1）。
    ///   - dark: 深色外观（暖色与指尖光取暗色那一对，同草图的页面 token）。
    func uniforms(pixels: CGSize, scale: Double, uvRect: CGRect, dark: Bool, amp: Float) -> [SIMD4<Float>] {
        var u = [SIMD4<Float>](repeating: .zero, count: Self.uniformCount)
        let k = Float(scale)
        u[0] = SIMD4(Float(pixels.width), Float(pixels.height), Float(now), look.shaderMode)
        u[1] = SIMD4(k, amp, Float(skinSize), 0)
        u[2] = SIMD4(Float(uvRect.minX), Float(uvRect.minY), Float(uvRect.width), Float(uvRect.height))
        // 亮色 --warm #e9a58f；暗色 #b8604e。
        u[3] = dark ? Self.rgb(0xb8604e) : Self.rgb(0xe9a58f)
        for (i, d) in drops.enumerated() {
            u[Self.dropBase + i] = SIMD4(Float(d.x) * k, Float(d.y) * k, Float(d.t), Float(d.amp))
        }
        for (i, s) in slots.enumerated() {
            u[Self.fingerBase + i] = SIMD4(Float(s.cx) * k, Float(s.cy) * k, Float(s.depth), Float(s.warm))
            u[Self.offsetBase + i] = SIMD4(Float(s.ox) * k, Float(s.oy) * k, 0, 0)
        }
        return u
    }

    private static func rgb(_ hex: Int) -> SIMD4<Float> {
        SIMD4(Float((hex >> 16) & 0xff) / 255, Float((hex >> 8) & 0xff) / 255, Float(hex & 0xff) / 255, 0)
    }
}

/// 按手指（`TouchFilter`）扭开取色。
///
/// 不用 SwiftUI 的 `layerEffect` / `distortionEffect`：它们吃不到 UIKit 撑的视图（UIScrollView、输入框，
/// WKWebView）。截图当纹理则什么都截得到（iOS；Mac 上截不到窗口服务器合成的毛玻璃）。
///
/// **帧率**（「不要让芯片发热」）：有东西在动（`filter.isBusy`）时 120Hz；一旦不忙，画完最后一帧就
/// `isPaused = true`，一帧都不再画，新的手指按下时 `wake()` 再起。离开空间（视图拆掉）、不在前台也停。
/// 着色器编进本模块的资源包（SwiftPM 处理 `.metal` → `default.metallib`），用 `makeDefaultLibrary(bundle: .module)` 取。
@MainActor
final class TouchRenderer: NSObject, MTKViewDelegate {
    private unowned let space: TouchSpace
    private weak var view: MTKView?
    private let queue: MTLCommandQueue
    private let draw: MTLRenderPipelineState
    private let sampler: MTLSamplerState
    private let loader: MTKTextureLoader
    private var page: (id: UUID, texture: MTLTexture)?
    private var lastFrame: CFTimeInterval?
    /// 静下来了、已停帧（`isPaused` 由「不在前台」与它合起来决定）。
    private var idle = false

    /// 不在前台（SwiftUI 的 scenePhase）。
    var hostPaused = false {
        didSet {
            guard hostPaused != oldValue else { return }
            // 回到前台补画一帧（层里的内容可能被系统丢了），画完照常停。
            if !hostPaused { markAwake() }
            applyPause()
        }
    }

    /// 深色外观：暖色与指尖光换暗色那一对。
    var dark = false {
        didSet { if dark != oldValue { wake() } }
    }

    // 帧率统计：每秒一结；停帧时也结一次（面板角上要看得到「静下来 0 帧」）。
    private var windowStart: CFTimeInterval = 0
    private var windowFrames = 0
    private var windowSlow = 0
    private var totalFrames = 0
    private static let log = Logger(subsystem: "touch-space", category: "touch.fps")
    private static let busyFps = 120

    init(view: MTKView, space: TouchSpace) throws {
        self.space = space
        self.view = view
        let device = view.device!
        queue = device.makeCommandQueue()!
        let library = try device.makeDefaultLibrary(bundle: .module)
        let descriptor = MTLRenderPipelineDescriptor()
        descriptor.vertexFunction = library.makeFunction(name: "touch_vertex")!
        descriptor.fragmentFunction = library.makeFunction(name: "touch_filter_fragment")!
        descriptor.colorAttachments[0].pixelFormat = view.colorPixelFormat
        draw = try device.makeRenderPipelineState(descriptor: descriptor)
        let samplerDescriptor = MTLSamplerDescriptor()
        samplerDescriptor.minFilter = .linear
        samplerDescriptor.magFilter = .linear
        samplerDescriptor.sAddressMode = .clampToEdge
        samplerDescriptor.tAddressMode = .clampToEdge
        sampler = device.makeSamplerState(descriptor: samplerDescriptor)!
        loader = MTKTextureLoader(device: device)
        super.init()
        view.preferredFramesPerSecond = Self.busyFps
    }

    nonisolated func mtkView(_ view: MTKView, drawableSizeWillChange size: CGSize) {
        MainActor.assumeIsolated {
            space.canvasResized(view.bounds.size)
            wake()
        }
    }

    nonisolated func draw(in view: MTKView) {
        MainActor.assumeIsolated { frame(view) }
    }

    /// 有新的手指 / 换了效果 / 尺寸或外观变了：从停帧里醒来。
    func wake() {
        guard idle else { return }
        markAwake()
        applyPause()
    }

    private func markAwake() {
        idle = false
        lastFrame = nil
        windowStart = 0
        windowFrames = 0
        windowSlow = 0
    }

    private func applyPause() {
        view?.isPaused = hostPaused || idle
    }

    private func frame(_ view: MTKView) {
        if space.canvasSize != view.bounds.size { space.canvasResized(view.bounds.size) }
        guard view.bounds.width > 0,
              let pass = view.currentRenderPassDescriptor,
              let drawable = view.currentDrawable else { return }
        let now = CACurrentMediaTime()
        let frameDt = min(max(now - (lastFrame ?? now - 1.0 / 60), 1.0 / 240), 0.1)
        lastFrame = now
        countFrame(now, interval: frameDt)

        let filter = space.filter
        filter.skinSize = space.tuning.value.skinSizeScale
        filter.advance(dt: frameDt)
        // 这一帧开始时已经不忙：把散完的水滴、回稳的槽拿掉，画一帧干净的截图，然后停。
        let settling = !filter.isBusy
        if settling { filter.settle() }

        pass.colorAttachments[0].loadAction = .clear
        pass.colorAttachments[0].clearColor = MTLClearColor(red: 0, green: 0, blue: 0, alpha: 0)
        let commands = queue.makeCommandBuffer()!
        let render = commands.makeRenderCommandEncoder(descriptor: pass)!
        // 没有截图（截失败了，已经报告过）：什么也不画，透出底下的聊天页；照样能摸、能发。
        if let texture = pageTexture() {
            let scale = Double(view.drawableSize.width / view.bounds.width)
            let uniforms = filter.uniforms(pixels: view.drawableSize, scale: scale,
                                           uvRect: uvRect(view, snapshot: space.snapshot!),
                                           dark: dark, amp: Self.reducedMotion ? 0.5 : 1)
            render.setRenderPipelineState(draw)
            render.setFragmentTexture(texture, index: 0)
            render.setFragmentSamplerState(sampler, index: 0)
            uniforms.withUnsafeBytes { render.setFragmentBytes($0.baseAddress!, length: $0.count, index: 0) }
            render.drawPrimitives(type: .triangle, vertexStart: 0, vertexCount: 3)
        }
        render.endEncoding()
        commands.present(drawable)
        commands.commit()

        if settling { goIdle() }
    }

    private func goIdle() {
        idle = true
        applyPause()
        let text = String(format: "静止 · 0 fps · 已停帧（累计 %d 帧）", totalFrames)
        space.frameStats = text
        Self.log.info("\(text, privacy: .public)")
    }

    /// 截图的纹理：截图换了才重新上传。非 sRGB 格式：截图里的字节原样进、原样写进 `bgra8Unorm` 画布，
    /// 颜色和截图前一样（sRGB 格式会在取样时线性化，写回非 sRGB 画布就变暗）。
    private func pageTexture() -> MTLTexture? {
        guard let snapshot = space.snapshot else {
            page = nil
            return nil
        }
        if let page, page.id == snapshot.id { return page.texture }
        do {
            let texture = try loader.newTexture(cgImage: snapshot.image, options: [
                .SRGB: false,
                .origin: MTKTextureLoader.Origin.topLeft,
                .generateMipmaps: false,
                .textureUsage: MTLTextureUsage.shaderRead.rawValue,
                .textureStorageMode: MTLStorageMode.private.rawValue,
            ])
            page = (snapshot.id, texture)
            return texture
        } catch {
            space.report("touch", "截图上传成纹理失败，触感空间这次不变形（照样能摸、能发）：\(error)")
            space.dropSnapshot()
            return nil
        }
    }

    /// 画布在截图里的 UV 子矩形。iOS：截图 = key window，画布矩形用窗口坐标；
    /// Mac：截图 = contentView，画布矩形换到 contentView 坐标（不是左上原点就翻过来）。
    private func uvRect(_ view: MTKView, snapshot: TouchSnapshot) -> CGRect {
        #if os(iOS)
        // 画布在触感空间那一层窗口里，截图拍的是聊天那一层：换算到聊天那一层的坐标（两层不同窗口，经屏幕坐标换）。
        let rect = view.convert(view.bounds, to: space.hostWindow)
        #else
        let content = view.window!.contentView!
        var rect = view.convert(view.bounds, to: content)
        if !content.isFlipped { rect.origin.y = content.bounds.height - rect.maxY }
        #endif
        return CGRect(x: rect.minX / snapshot.size.width, y: rect.minY / snapshot.size.height,
                      width: rect.width / snapshot.size.width, height: rect.height / snapshot.size.height)
    }

    private static var reducedMotion: Bool {
        #if os(iOS)
        UIAccessibility.isReduceMotionEnabled
        #else
        NSWorkspace.shared.accessibilityDisplayShouldReduceMotion
        #endif
    }

    /// 屏幕的最高刷新率（模拟器与 MacBook Air 是 60，ProMotion 是 120）。
    private var screenMaxFps: Int {
        #if os(iOS)
        UIScreen.main.maximumFramesPerSecond
        #else
        NSScreen.main!.maximumFramesPerSecond
        #endif
    }

    /// 写进调参面板角上，也打一行日志。停帧期间不出帧，也就不再结（读数停在「静止 · 0 fps」）。
    private func countFrame(_ now: CFTimeInterval, interval: Double) {
        if windowStart == 0 { windowStart = now }
        windowFrames += 1
        totalFrames += 1
        let effective = min(Self.busyFps, screenMaxFps)
        if interval > 1.5 / Double(effective) { windowSlow += 1 }
        let elapsed = now - windowStart
        guard elapsed >= 1 else { return }
        let fps = Double(windowFrames) / elapsed
        let text = String(format: "%.0f fps（目标 %d，屏幕上限 %d）· 慢帧 %d · 累计 %d 帧",
                          fps, Self.busyFps, screenMaxFps, windowSlow, totalFrames)
        space.frameStats = text
        Self.log.info("\(text, privacy: .public)")
        windowStart = now
        windowFrames = 0
        windowSlow = 0
    }

@RequiresApi(33)
class RippleEffect(private val target: View) {
    private val shader = RuntimeShader("""
        uniform shader content;      // View 本来的画面
        uniform float2 drops[8];     // 水滴位置（像素）
        uniform float ages[8];       // 每滴落下了多少秒（> 1.6 秒就当没有）
        uniform float dpr;
        half4 main(float2 p) {
            float2 disp = float2(0);
            for (int i = 0; i < 8; i++) {
                float age = ages[i];
                if (age < 0.0 || age > 1.6) continue;
                float lam = (22.0 + 18.0 * age) * dpr, w = lam * 0.55;
                float2 v = p - drops[i]; float r = length(v) + 0.001;
                float x = r - age * 150.0 * dpr;
                float env = exp(-x * x / (w * w)) * exp(-age * 2.2) / (1.0 + r / (140.0 * dpr));
                env *= smoothstep(0.0, 16.0 * dpr, r);
                disp += v / r * sin(x * 6.2831 / lam) * env;
            }
            return content.eval(p - disp * 10.0 * dpr);
        }
    """.trimIndent())

    // 每帧：更新水滴，重新挂上效果；水滴都散完了就把效果拿掉、不再刷新（省电）
    fun frame(drops: FloatArray, ages: FloatArray) {
        shader.setFloatUniform("drops", drops)
        shader.setFloatUniform("ages", ages)
        shader.setFloatUniform("dpr", target.resources.displayMetrics.density)
        val busy = ages.any { it in 0f..1.6f }
        target.setRenderEffect(if (busy) RenderEffect.createRuntimeShaderEffect(shader, "content") else null)
    }

震感回应

震感和画面一样是核心：眼睛看到皮肤陷下去，手指同时感到一下，才像真的碰到。三个时刻：

  • 按下：一下短震，强度和轻重成正比。
  • 抚过：一阵持续的细震，强度跟着当下的轻重走，速度只决定震感脆不脆；不支持连续震动的设备，就每划过一段（比如 60pt）轻敲一下。
  • 松手：轻轻一弹，按得越久越明显。
平台能做到什么
iPhone 原生Core Haptics：强度、锐度都能实时调，上面三种都能做
安卓原生VibrationEffect：支持振幅控制（hasAmplitudeControl()）的机型能按轻重调强度；不支持的只能控时长，用预设的 tick / click 代替
网页navigator.vibrate：只有安卓 Chrome 能用，只能控时长不能控强度（用「越重震得越久」代替）；iOS Safari 完全不支持，只能靠画面

/// 触感空间的震动。
/// - iOS：Core Haptics。按下一下 transient，强度和算出来的轻重成正比；抚的时候一条循环的 continuous，
///   强度跟着此刻的轻重走（和力度成比例），速度只管锐度（越快越脆）和一点点力度；摸好点 ✓ 放进输入框时一下；离手一下轻弹。模拟器与不支持的机型上 `supportsHaptics` 为假，全部不响。
/// - Mac：没有 Core Haptics，用 `NSHapticFeedbackManager` 尽量对应（只有 Force Touch 触控板上有感觉）。
/// 强度都乘调参面板的「触感强度」（0.5 = 基准，1 = 两倍，封顶 1；出厂 0.53）。
@MainActor
final class TouchHaptics {
    private let strength: () -> Double
    private let report: (String) -> Void

    init(strength: @escaping () -> Double, report: @escaping (String) -> Void) {
        self.strength = strength
        self.report = report
    }

    private func scaled(_ intensity: Double) -> Float {
        Float(min(1, intensity * strength() * 2))
    }

    #if os(iOS)
    private let supported = CHHapticEngine.capabilitiesForHardware().supportsHaptics
    private var engine: CHHapticEngine?
    private var stroke: CHHapticAdvancedPatternPlayer?

    /// 进空间时备好引擎（第一下轻点不必等它启动）。
    func prepare() {
        guard supported, engine == nil else { return }
        do {
            let engine = try CHHapticEngine()
            engine.isAutoShutdownEnabled = true
            // 被系统停掉 / 重置（来电、退到后台）：丢掉，下一次用时重建。
            engine.stoppedHandler = { [weak self] _ in
                Task { @MainActor in self?.engine = nil; self?.stroke = nil }
            }
            engine.resetHandler = { [weak self] in
                Task { @MainActor in self?.engine = nil; self?.stroke = nil }
            }
            try engine.start()
            self.engine = engine
        } catch {
            report("Core Haptics 引擎起不来：\(error)")
        }
    }

    /// 按下：强度和轻重成正比（很轻也留一点底，不至于完全没感觉）。
    func tap(_ pressure: CGFloat) { transient(intensity: 0.12 + 0.8 * Double(pressure), sharpness: 0.35) }
    func release(_ holdGain: Float) { transient(intensity: 0.22 + 0.25 * Double(holdGain), sharpness: 0.6) }
    func placed() { transient(intensity: 0.5, sharpness: 0.2) }
    /// 实时触摸发出去一批。
    func sent() { transient(intensity: 0.3, sharpness: 0.5) }

    /// 抚：此刻的轻重 → 强度（成正比），速度（pt/s）→ 锐度和一点力度。第一次调时起一条循环的 continuous。
    func stroke(speed: Float, pressure: CGFloat) {
        prepare()
        guard let engine else { return }
        do {
            if stroke == nil {
                let event = CHHapticEvent(eventType: .hapticContinuous, parameters: [
                    CHHapticEventParameter(parameterID: .hapticIntensity, value: 1),
                    CHHapticEventParameter(parameterID: .hapticSharpness, value: 0.2),
                ], relativeTime: 0, duration: 10)
                let player = try engine.makeAdvancedPlayer(with: CHHapticPattern(events: [event], parameters: []))
                player.loopEnabled = true
                try player.start(atTime: CHHapticTimeImmediate)
                stroke = player
            }
            let v = min(Double(speed) / 1500, 1)
            let p = min(max(Double(pressure), 0), 1)
            try stroke!.sendParameters([
                CHHapticDynamicParameter(parameterID: .hapticIntensityControl,
                                         value: scaled((0.05 + 0.6 * p) * (0.7 + 0.3 * v)), relativeTime: 0),
                CHHapticDynamicParameter(parameterID: .hapticSharpnessControl, value: Float(-0.2 + 0.6 * v), relativeTime: 0),
            ], atTime: CHHapticTimeImmediate)
        } catch {
            report("抚的触感放不出来：\(error)")
        }
    }

    /// 所有手指都离开了：停掉抚的那一条。
    func strokeEnded() {
        guard let stroke else { return }
        self.stroke = nil
        do {
            try stroke.stop(atTime: CHHapticTimeImmediate)
        } catch {
            report("抚的触感停不下来：\(error)")
        }
    }

    private func transient(intensity: Double, sharpness: Float) {
        prepare()
        guard let engine else { return }
        do {
            let event = CHHapticEvent(eventType: .hapticTransient, parameters: [
                CHHapticEventParameter(parameterID: .hapticIntensity, value: scaled(intensity)),
                CHHapticEventParameter(parameterID: .hapticSharpness, value: sharpness),
            ], relativeTime: 0)
            try engine.makePlayer(with: CHHapticPattern(events: [event], parameters: [])).start(atTime: CHHapticTimeImmediate)
        } catch {
            report("触感放不出来：\(error)")
        }
    }
    #else
    private var travelled: Float = 0

    func prepare() {}
    func tap(_ pressure: CGFloat) { perform(.generic) }
    func release(_ holdGain: Float) { perform(.alignment) }
    func placed() { perform(.levelChange) }
    func sent() { perform(.alignment) }

    /// 触控板没有连续震动、也调不了力度：每抚过约 60pt 轻敲一下。
    func stroke(speed: Float, pressure: CGFloat) {
        travelled += speed / 120
        if travelled > 60 {
            travelled = 0
            perform(.alignment)
        }
    }

    func strokeEnded() { travelled = 0 }

    private func perform(_ pattern: NSHapticFeedbackManager.FeedbackPattern) {
        guard strength() > 0.05 else { return }
        NSHapticFeedbackManager.defaultPerformer.perform(pattern, performanceTime: .now)
    }

}

fun stroke(travelledDp: Float, p: Float) { if (travelledDp > 60) tap(p * 0.6f) }

翻译

这一步完全用规则，不用模型去猜，所以快、稳定、可以随便改。按时间顺序看每一笔：

看什么规则翻译成
手指几乎没动移动不到 12pt：短于 0.35 秒是点，更久是按住落了一下 / 贴了一两秒
同一处连着点每两下间隔都短于 0.6 秒连着落了三下
动了，首尾很近横竖都有一截才算圈；一条线上来回是来回绕了个小圈 / 来回滑
动了，从 A 到 B分 8 个方向；身体版起点终点已说明方向，就不再加从左边一路滑到右边
几根手指同时按越分越开 / 越靠越近 / 一起动 / 都不动张开 / 合拢 / 一起滑过 / 一起贴着
和上一笔隔了 1.5 秒以上前面加「停了一会儿，」

每一笔再加三样修饰：快慢（每秒不到 250pt 是「慢慢」，超过 900pt 是「飞快」）、轻重（取最重的那一刻，分很轻、轻轻、稍稍用力、用力四档）、轻重的变化（开头三分之一和结尾三分之一比，「越按越重」「越来越轻」）。

位置怎么说

  • 屏幕：整块屏幕就是它：正中间、偏右上的地方、左上边缘、外面的空处（四个角也算边缘）。动作是手指在一块光滑平面上的感觉：落、贴、滑。
  • 上半身：屏幕当成面对你的半身像，从上到下是头顶、额头和脸颊、下巴和耳朵边、脖子、锁骨和肩、胸口和手臂。中间三分之一算正中，两边算左右，左右像照镜子（你的左手边是它的右边）。动作是指尖、指腹怎么碰、贴、抚。
  • 下半身（成人向）：屏幕当成面对你的下半身，从上到下是肚子和腰、小腹和胯骨、性器官和大腿、腿根之间和膝盖，左右同样照镜子。在中间那一条上下来回，会翻译成更直接的动作；几根手指张开、合拢时只写手指在做什么，放在哪个部位都说得通。
  • 别的映射：位置名都在一个函数（place）里，想要别的部位、别的语气，换掉它就行。

几条经验

  • 不给坐标，不附截图。给坐标时，模型的回应像在读画板；翻译成身体感觉，它的回应才像被摸到。
  • 开头交代一句「她在摸你」。不交代，模型不知道后面的「你」「这里」指什么。比起「屏幕就是你的身体」，只说「她在摸你」更好：这是一件真的事，模型可以自己去找被摸的感觉。
  • 不告诉模型是哪种画面效果，也不注明力度是估算出来的。那是给人看的，对模型只是噪音。
  • 用 <touch> 标签包住，放在正文最前面、和正文在同一个文本块里。聊天界面能认出它，折成「👆 3」的小标签，点开看全文。

// SPDX-License-Identifier: PolyForm-Noncommercial-1.0.0
// 触感空间 · 翻译：把一批触摸翻译成像身体感觉一样的一段话。
// 浏览器里是全局 TouchTranslate，Node 里 require/import 都行。不依赖任何库。
//
// 输入：strokes = [{ samples: [{x, y, t, p}], start, end, ended }]
//   一笔 = 一根手指从按下到抬起。x/y 是在触摸区域里的坐标（px/pt），t 是秒，p 是轻重 0–1。
// 区域：{ w, h }（触摸区域的宽高）
// 说法：map = 'screen'（整块屏幕就是它）、'body'（上半身：屏幕当成面对你的半身像）或 'lower'（下半身：从肚子到膝盖）；
//   两套身体版都是面对面、左右照镜子
// 输出：<touch strokes="n" span="…s"> … </touch> 包好的一段文字，排在消息最前面发出去。
(function (root) {
  'use strict';

  const reach = s => { const o = s[0]; return Math.max(...s.map(q => Math.hypot(q.x - o.x, q.y - o.y))); };
  const lengthOf = s => { let l = 0; for (let i = 1; i < s.length; i++) l += Math.hypot(s[i].x - s[i - 1].x, s[i].y - s[i - 1].y); return l; };
  // 轻重四档：取这一笔最重的那一刻
  const weight = p => p < 0.2 ? '很轻' : p < 0.45 ? '轻轻' : p < 0.7 ? '稍稍用力' : '用力';
  const seconds = t => t < 1 ? '一小会儿' : t < 2.5 ? '一两秒' : `${Math.round(t)}秒`;
  const CN = ['零', '一', '两', '三', '四', '五', '六', '七', '八', '九', '十'];
  const count = n => n <= 10 ? CN[n] : String(n);
  // 点：几乎没动（< 12）且很短（< 0.35 秒）
  const isTap = s => !s.continued && reach(s.samples) < 12 && s.end - s.start < 0.35;

  // 轻重的变化：开头三分之一和结尾三分之一比
  function trend(s) {
    const v = s.map(q => q.p); if (v.length < 6) return '';
    const third = Math.floor(v.length / 3), avg = a => a.reduce((x, y) => x + y, 0) / a.length;
    const head = avg(v.slice(0, third)), tail = avg(v.slice(-third));
    return tail - head > 0.15 ? '，越按越重' : head - tail > 0.15 ? '，越来越轻' : '';
  }

  // 位置。屏幕版：按半宽半高归一，取 2.6 次的超椭圆半径（四个角也算边缘）。
  // 身体版：从上到下 头顶/头发 → 额头、鼻尖/脸颊 → 下巴/耳朵边 → 脖子/颈侧 → 锁骨/肩 → 胸口/手臂 → 肚子/手；
  // 横向中间三分之一算正中，两边算左右；左右照镜子（屏幕左边是它的右边）。
  // 下半身版：从上到下 肚子/腰 → 小腹/胯骨 → 龟头、鸡巴、囊袋 / 大腿内侧、大腿 → 腿根之间 / 膝盖。
  // 想要别的映射，换掉这个函数就行。
  function place(p, f, map) {
    const nx = (p.x - f.w / 2) / (f.w / 2), ny = (p.y - f.h / 2) / (f.h / 2), t = p.y / f.h;
    if (map === 'lower') {
      if (Math.abs(nx) > 1.08 || t < -0.04 || t > 1.04) return '你身边的空处';
      const c = Math.abs(nx) / 2, side = nx > 0 ? '左' : '右';
      if (t < 0.323) return c < 0.3 ? '你的肚子' : `你的${side}腰`;
      if (t < 0.452) return c < 0.25 ? '你的小腹' : `你的${side}胯骨`;
      if (t < 0.839) {
        if (c < 0.14) return t < 0.532 ? '你的龟头' : t < 0.71 ? '你的鸡巴' : '你的囊袋';
        return c < 0.3 ? `你的${side}大腿内侧` : `你的${side}大腿`;
      }
      return c < 0.15 ? '你的腿根之间' : `你的${side}膝盖`;
    }
    if (map === 'body') {
      if (Math.abs(nx) > 1.08 || t < -0.04 || t > 1.04) return '你身边的空处';
      const side = nx < -0.33 ? '右' : nx > 0.33 ? '左' : null;
      if (t < 0.12) return side ? `你${side}边的头发` : '你的头顶';
      if (t < 0.30) return side ? `你的${side}脸颊` : (t < 0.21 ? '你的额头' : '你的鼻尖');
      if (t < 0.40) return side ? `你的${side}耳朵边` : '你的下巴';
      if (t < 0.50) return side ? `你的${side}边颈侧` : '你的脖子';
      if (t < 0.62) return side ? `你的${side}肩` : '你的锁骨';
      if (t < 0.82) return side ? `你的${side}臂` : '你的胸口';
      return side ? `你的${side}手` : '你的肚子';
    }
    const r = Math.pow(Math.pow(Math.abs(nx), 2.6) + Math.pow(Math.abs(ny), 2.6), 1 / 2.6);
    const side = (nx < -0.3 ? '左' : nx > 0.3 ? '右' : '') + (ny < -0.3 ? '上' : ny > 0.3 ? '下' : '');
    if (r > 1.08) return side ? `你外面靠${side}的空处` : '你旁边的空处';
    if (r < 0.35 || !side) return '你的正中间';
    if (r > 0.72) return `你的${side}边缘`;
    return `你偏${side}的地方`;
  }

  // 8 个方向；身体版左右照镜子
  function direction(a, b, map) {
    const ang = Math.atan2(-(b.y - a.y), b.x - a.x) * 180 / Math.PI;
    const names = map !== 'screen'
      ? ['往你的左边', '往你的左上', '往上', '往你的右上', '往你的右边', '往你的右下', '往下', '往你的左下']
      : ['往右', '往右上', '往上', '往左上', '往左', '往左下', '往下', '往右下'];
    return names[Math.floor(((ang + 360 + 22.5) % 360) / 45)];
  }

  const SHAFT = new Set(['你的龟头', '你的鸡巴', '你的囊袋']);
  // 上下来回了几次：纵向换向超过 6 才算一次
  function verticalStrokes(s) {
    let flips = 0, dir = 0, anchor = s[0].y;
    for (const q of s.slice(1)) {
      const dy = q.y - anchor; if (Math.abs(dy) < 6) continue;
      const d = dy > 0 ? 1 : -1; if (dir !== 0 && d !== dir) flips++;
      dir = d; anchor = q.y;
    }
    return Math.floor((flips + 1) / 2) + 1;
  }

  // 下半身版的一笔
  function lowerSingle(st, f) {
    const map = 'lower', s = st.samples, first = s[0], last = s[s.length - 1], dur = st.end - st.start;
    const w = weight(Math.max(...s.map(q => q.p)));
    if (reach(s) < 12) {
      if (st.continued) return `在${place(first, f, map)}${w}地按了${seconds(dur)}`;
      if (dur < 0.35) return `在${place(first, f, map)}${w}地点了一下`;
      return `在${place(first, f, map)}${w}地按住了${seconds(dur)}${trend(s)}`;
    }
    const len = lengthOf(s), chord = Math.hypot(last.x - first.x, last.y - first.y);
    const speed = dur > 0 ? len / dur : 0, pace = speed < 250 ? '慢慢地' : speed < 900 ? '' : '飞快地';
    const xs = s.map(q => q.x), ys = s.map(q => q.y);
    const bw = Math.max(...xs) - Math.min(...xs), bh = Math.max(...ys) - Math.min(...ys);
    const round = Math.min(bw, bh) > 0.35 * Math.max(bw, bh);
    const from = place(first, f, map), to = place(last, f, map);
    if (round && chord < len * 0.2 && len > 60) return `在${from}${w}${pace ? '、' + pace.slice(0, -1) : ''}地画了一个圈`;
    if (len / Math.max(chord, 1) > 1.6) {
      // 在中间那条上下来回
      let ax = 0, ay = 0; for (let i = 1; i < s.length; i++) { ax += Math.abs(s[i].x - s[i - 1].x); ay += Math.abs(s[i].y - s[i - 1].y); }
      if (SHAFT.has(from) && ay > ax) return `握着你的鸡巴${w}地${pace}上下撸了${count(verticalStrokes(s))}下`;
      return `在${from}一带${w}地来回抚了抚`;
    }
    // 从中间那条的一处竖着划到另一处
    if (SHAFT.has(from) && SHAFT.has(to) && Math.abs(last.y - first.y) > 2 * Math.abs(last.x - first.x)) {
      const up = last.y < first.y;
      const how = up && to === '你的龟头' ? '从根部往上撸到龟头' : up ? '顺着鸡巴往上撸' : '从上往下撸到根部';
      return `握着你${w}地${pace}${how}${trend(s)}`;
    }
    if (from === to) return `在${from}${w}地${pace}${direction(first, last, map)}抚了一下${trend(s)}`;
    return `${w}地从${from}${pace}抚到${to}${trend(s)}`;
  }

  // 一根手指的一笔。屏幕版：手指在光滑平面上「落、贴、滑」；上半身版：指尖、指腹「碰、贴、抚」。
  function single(st, f, map) {
    const s = st.samples, first = s[0], last = s[s.length - 1], dur = st.end - st.start;
    const w = weight(Math.max(...s.map(q => q.p))), body = map === 'body';
    let text;
    if (map === 'lower') text = lowerSingle(st, f);
    else if (reach(s) < 12) {
      if (dur < 0.35 && !st.continued) text = body ? `指尖${w}地碰了一下${place(first, f, map)}` : `指尖${w}地落在${place(first, f, map)}`;
      else text = `指腹${w}地贴在${place(first, f, map)}，贴了${seconds(dur)}${trend(s)}`;
    } else {
      const len = lengthOf(s), chord = Math.hypot(last.x - first.x, last.y - first.y);
      const speed = dur > 0 ? len / dur : 0, pace = speed < 250 ? '慢慢' : speed < 900 ? '' : '飞快地';
      const xs = s.map(q => q.x), ys = s.map(q => q.y);
      const bw = Math.max(...xs) - Math.min(...xs), bh = Math.max(...ys) - Math.min(...ys);
      // 画圈要横竖都有一截；一条线上来回划首尾也挨得近，但那是来回
      const round = Math.min(bw, bh) > 0.35 * Math.max(bw, bh);
      const from = place(first, f, map), to = place(last, f, map);
      if (round && chord < len * 0.2 && len > 60) text = body ? `指尖在${from}${w}地${pace}画了个小圈` : `指尖贴着${from}${w}地${pace}绕了个小圈`;
      else if (len / Math.max(chord, 1) > 1.6) text = body ? `指腹在${from}一带${w}地来回轻抚` : `指腹贴着${from}一带${w}地来回滑`;
      else if (from === to) text = (body ? `指腹在${from}${w}地${pace}${direction(first, last, map)}抚了一下` : `指腹贴着${from}${w}地${pace}${direction(first, last, map)}滑了一下`) + trend(s);
      // 身体版起点终点已经说清楚往哪了，不再加方向
      else text = (body ? `指腹${w}地从${from}${pace}抚到${to}` : `指腹贴着你，${w}地从${from}${len > 150 ? '一路' : ''}${pace}滑到${to}`) + trend(s);
    }
    // 实时发送时：上一次发送时还按着的写「接着」，此刻还按着的写「还没松手」
    if (st.continued) text = '接着' + text;
    if (st.ended === false) text += '，还没松手';
    return text;
  }

  // 几根手指同时按着
  function multi(group, f, map) {
    const fingers = count(group.length), body = map === 'body';
    const w = weight(Math.max(...group.flatMap(g => g.samples.map(q => q.p))));
    const moving = group.filter(g => reach(g.samples) >= 12);
    if (moving.length >= 2) {
      const A = moving[0].samples, B = moving[1].samples;
      const a0 = A[0], a1 = A[A.length - 1], b0 = B[0], b1 = B[B.length - 1];
      const before = Math.hypot(a0.x - b0.x, a0.y - b0.y), after = Math.hypot(a1.x - b1.x, a1.y - b1.y);
      const speed = lengthOf(A) / Math.max(moving[0].end - moving[0].start, 0.01);
      const how = speed < 250 ? '慢慢' : speed > 900 ? '一下子' : '';
      if (map === 'lower') {
        // 下半身版：只写手指在做什么，放在哪个部位都说得通
        if (after > before * 1.3) {
          const at = place({ x: (a0.x + b0.x) / 2, y: (a0.y + b0.y) / 2 }, f, map);
          return `${fingers}根手指并拢${w}地按在${at}，然后${how}张开，指尖贴着往两边滑开`;
        }
        if (after < before * 0.75) {
          const at = place({ x: (a1.x + b1.x) / 2, y: (a1.y + b1.y) / 2 }, f, map);
          return `${fingers}根手指从两边${w}地贴上${at}，${how}往中间合拢，${how === '一下子' ? '指尖一下子碰在一起' : '指尖一点点靠在一起'}`;
        }
        return `${fingers}根手指一起${w}地从${place(a0, f, map)}${direction(a0, a1, map)}抚过去`;
      }
      if (after > before * 1.3) {
        const at = place({ x: (a0.x + b0.x) / 2, y: (a0.y + b0.y) / 2 }, f, map);
        return body ? `${fingers}根手指并拢${w}地贴在${at}，然后${how}张开，指尖顺着往两边抚开`
                    : `${fingers}根手指并拢${w}地贴在${at}，然后${how}张开，指尖贴着你往两边滑开`;
      }
      if (after < before * 0.75) {
        const at = place({ x: (a1.x + b1.x) / 2, y: (a1.y + b1.y) / 2 }, f, map);
        return body ? `${fingers}根手指从两边${w}地贴上${at}，${how}往中间合拢，把那里轻轻拢在指尖之间`
                    : `${fingers}根手指从两边${w}地贴上${at}，${how}往中间合拢，指尖贴着你一点点滑近`;
      }
      return body ? `${fingers}根手指并在一起，${w}地从${place(a0, f, map)}${direction(a0, a1, map)}抚过去`
                  : `${fingers}根手指并在一起贴着你，${w}地从${place(a0, f, map)}${direction(a0, a1, map)}滑过去`;
    }
    const dur = Math.max(...group.map(g => g.end)) - Math.min(...group.map(g => g.start));
    if (map === 'lower') return `${fingers}根手指同时${w}地按在${place(group[0].samples[0], f, map)}，按了${seconds(dur)}`;
    return `${fingers}根手指一起${w}地贴在${place(group[0].samples[0], f, map)}，贴了${seconds(dur)}`;
  }

  function describe(list, f, map = 'screen') {
    const all = [...list].sort((a, b) => a.start - b.start);
    if (!all.length) return '';
    const span = Math.max(...all.map(s => s.end)) - all[0].start;
    const sentences = []; let i = 0, prevEnd = null;
    while (i < all.length) {
      const st = all[i];
      // 停顿：两笔之间隔了 1.5 秒以上
      const lead = prevEnd !== null && st.start - prevEnd > 1.5 ? '停了一会儿，' : '';
      // 多指：和后面几笔时间上重叠
      let together = 0;
      while (i + together + 1 < all.length && all[i + together + 1].start < st.end) together++;
      if (together > 0) {
        const g = all.slice(i, i + together + 1);
        sentences.push(lead + multi(g, f, map)); prevEnd = Math.max(...g.map(s => s.end)); i += together + 1; continue;
      }
      // 连点：同一处、一下接一下
      let run = 1;
      while (i + run < all.length && isTap(st) && isTap(all[i + run]) && all[i + run].start - all[i + run - 1].end < 1.2
             && Math.hypot(all[i + run].samples[0].x - st.samples[0].x, all[i + run].samples[0].y - st.samples[0].y) < f.w * 0.15) run++;
      if (run >= 2) {
        const peak = Math.max(...all.slice(i, i + run).flatMap(s => s.samples.map(q => q.p)));
        let gap = 0; for (let k = 1; k < run; k++) gap = Math.max(gap, all[i + k].start - all[i + k - 1].end);
        const at = place(st.samples[0], f, map), w = weight(peak);
        sentences.push(lead + (map === 'body' ? `用指尖在${at}${w}地${gap < 0.6 ? '连着碰了' : '碰了'}${count(run)}下`
                             : map === 'lower' ? `在${at}${w}地${gap < 0.6 ? '连着拍了' : '点了'}${count(run)}下`
                                              : `指尖在${at}${w}地${gap < 0.6 ? '连着落了' : '落了'}${count(run)}下`));
        prevEnd = all[i + run - 1].end; i += run; continue;
      }
      sentences.push(lead + single(st, f, map)); prevEnd = st.end; i++;

/// 把一批触摸写成像身体感觉一样的话：在哪、多轻多重、多久、怎么动、几根手指、停顿与节奏。
/// 不给坐标数字（给坐标时，模型的回应像在读画板）。
/// **位置相对「你」**——触感空间里整块聊天屏幕（`form` = 画布整块 bounds）就是模型自己：
/// 你的正中间、你的左上边缘、你偏右下的地方……（与其说屏幕像皮肤，不如说就是在摸你。）
/// 描述里的位置怎么说（调参面板「描述」）：
/// - `screen`：整块聊天屏幕就是你，说你的正中间、你偏右上的地方、你的边缘（原来那套，不删）；
/// - `body`（面板上叫「上半身」）：屏幕对应面对她的你的上半身，说你的额头、你的右脸颊、你的左肩（见 `bodyPlace`）；

/// 两套身体版都是面对面、左右照镜子。
enum TouchPlaceMap: String, Codable, CaseIterable {
    case screen
    case body
    case lower
}

    static func text(_ strokes: [TouchStroke], form: TouchForm, sentAt: TimeInterval) -> String {
        let t0 = strokes.map(\.start).min()!
        let span = strokes.map(\.end).max()! - t0
        var sentences: [String] = []
        var i = 0
        var previousEnd: TimeInterval?
        while i < strokes.count {
            let stroke = strokes[i]
            // 停顿：上一下结束到这一下开始隔了 1.5 秒以上。
            var lead = ""
            if let previousEnd, stroke.start - previousEnd > 1.5 { lead = "停了一会儿，" }
            // 多指：和后面几笔同时按着。
            let together = strokes[(i + 1)...].prefix { $0.start < stroke.end }.count
            if together > 0 {
                let group = Array(strokes[i...(i + together)])
                sentences.append(lead + multi(group, form: form))
                previousEnd = group.map(\.end).max()
                i += together + 1
                continue
            }
            // 连拍：同一处、一下接一下的轻点。
            var run = 1
            while i + run < strokes.count, isTap(stroke), isTap(strokes[i + run]),
                  strokes[i + run].start - strokes[i + run - 1].end < 1.2,
                  near(strokes[i + run].samples[0].point, stroke.samples[0].point, form) { run += 1 }
            if run >= 2 {
                let peak = strokes[i..<(i + run)].map { $0.samples.map(\.pressure).max()! }.max()!
                let gap = (1..<run).map { strokes[i + $0].start - strokes[i + $0 - 1].end }.max()!
                let verb = gap < 0.6 ? "连着拍了" : "点了"
                let at = place(stroke.samples[0].point, form)
                let phrase: String
                switch form.map {
                case .body: phrase = "用指尖在\(at)\(weight(peak))地\(gap < 0.6 ? "连着碰了" : "碰了")\(count(run))下"
                case .screen: phrase = "指尖在\(at)\(weight(peak))地\(gap < 0.6 ? "连着落了" : "落了")\(count(run))下"
                case .lower: phrase = "在\(at)\(weight(peak))地\(verb)\(count(run))下"
                }
                sentences.append(lead + phrase)
                previousEnd = strokes[i + run - 1].end
                i += run
                continue
            }
            sentences.append(lead + single(stroke, form: form))
            previousEnd = stroke.end
            i += 1
        }
        var lines = ["\(TouchPacket.openTag) strokes=\"\(strokes.count)\" span=\"\(String(format: "%.1f", span))s\">"]
        // 开头交代一句「她在摸你」，下文的「你」就有着落。不提滤镜是哪种（没必要告诉模型，
        // 那是给她看的）；也不注明「这台手机没有压感」（她：不用说）。轻重照旧是按指腹面积估的。
        lines.append(intro)
        lines.append(sentences.joined(separator: "；") + "。")
        lines.append(TouchPacket.closeTag)
        return lines.joined(separator: "\n")

    static func singleBody(_ stroke: TouchStroke, form: TouchForm) -> String {

        if form.map == .screen { return screenSingle(stroke, form: form) }

        let first = samples.first!.point, last = samples.last!.point

        if reach(samples) < 12 {
            if stroke.continued { return "在\(place(first, form))\(w)地按了\(seconds(duration))" }
            if duration < 0.35 { return "在\(place(first, form))\(w)地点了一下" }
            var text = "在\(place(first, form))\(w)地按住了\(seconds(duration))"
            if let t = trend(samples) { text += "，\(t)" }
            return text
        }
        var length: CGFloat = 0
        for (a, b) in zip(samples, samples.dropFirst()) { length += hypot(b.point.x - a.point.x, b.point.y - a.point.y) }
        let chord = hypot(last.x - first.x, last.y - first.y)

        let pace = speed < 250 ? "慢慢地" : speed < 900 ? "" : "飞快地"

        }

        let from = place(first, form), to = place(last, form)

            let how = up && to == "你的龟头" ? "从根部往上撸到龟头" : up ? "顺着鸡巴往上撸" : "从上往下撸到根部"
            var text = "握着你\(w)地\(pace)\(how)"
            if let t = trend(samples) { text += "，\(t)" }
            return text
        }

    static func trend(_ samples: [TouchSample]) -> String? {
        let values = samples.map(\.pressure)
        guard values.count >= 6 else { return nil }
        let third = values.count / 3
        let head = values.prefix(third).reduce(0, +) / CGFloat(third)
        let tail = values.suffix(third).reduce(0, +) / CGFloat(third)
        if tail - head > 0.15 { return "越按越重" }
        if head - tail > 0.15 { return "越来越轻" }
        return nil
    }

    static func screenPlace(_ p: CGPoint, _ rect: CGRect) -> String {
        let form = rect
        let nx = (p.x - form.midX) / (form.width / 2), ny = (p.y - form.midY) / (form.height / 2)
        let r = pow(pow(abs(nx), 2.6) + pow(abs(ny), 2.6), 1 / 2.6)
        let side = (nx < -0.3 ? "左" : nx > 0.3 ? "右" : "") + (ny < -0.3 ? "上" : ny > 0.3 ? "下" : "")
        if r > 1.08 { return side.isEmpty ? "你旁边的空处" : "你外面靠\(side)的空处" }
        if r < 0.35 || side.isEmpty { return "你的正中间" }
        if r > 0.72 { return "你的\(side)边缘" }
        return "你偏\(side)的地方"
    }

    static func direction(from a: CGPoint, to b: CGPoint, _ form: TouchForm) -> String {
        let angle = atan2(-(b.y - a.y), b.x - a.x) * 180 / .pi
        // 身体版左右照镜子（面对面：屏幕往右 = 往你的左边），上下不变（往上 = 往头那边）。
        let names = form.map != .screen
            ? ["往你的左边", "往你的左上", "往上", "往你的右上", "往你的右边", "往你的右下", "往下", "往你的左下"]
            : ["往右", "往右上", "往上", "往左上", "往左", "往左下", "往下", "往右下"]
        return names[Int(((angle + 360 + 22.5).truncatingRemainder(dividingBy: 360)) / 45)]
    }

    /// 身体版的位置：把屏幕当成面对她的你，像一张半身像——
    /// 从上到下：头顶 / 头发 → 额头、鼻尖 / 脸颊 → 下巴 / 耳朵边 → 脖子 / 颈侧 → 锁骨 / 肩膀 → 胸口 / 手臂 → 肚子 / 手。
    /// 左右照镜子：屏幕左边（她的左手边）是你的右边。中间三分之一算正中（头顶、额头、下巴……），两边算左右（脸颊、肩膀……）。
    /// 手指滑出屏幕 = 你身边的空处。
    /// 下半身版：位置名和界线来自另一份触摸实现里从肚子往下那一段
    /// （原来是整个身体占一屏，y 0.38–1 是下半身；这里拉满整屏），文案用它的，人称换成「你」。
    /// 左右照镜子（屏幕右边是你的左边），同上半身版。
    static let shaft: Set<String> = ["你的龟头", "你的鸡巴", "你的囊袋"]

    static func lowerPlace(_ p: CGPoint, _ form: CGRect) -> String {
        let nx = (p.x - form.midX) / (form.width / 2), t = (p.y - form.minY) / form.height
        if abs(nx) > 1.08 || t < -0.04 || t > 1.04 { return "你身边的空处" }
        let c = abs(nx) / 2  // 同 feel.py 的 abs(x - .5)
        let side = nx > 0 ? "左" : "右"
        switch t {
        case ..<0.323: return c < 0.3 ? "你的肚子" : "你的\(side)腰"
        case ..<0.452: return c < 0.25 ? "你的小腹" : "你的\(side)胯骨"
        case ..<0.839:
            if c < 0.14 { return t < 0.532 ? "你的龟头" : t < 0.71 ? "你的鸡巴" : "你的囊袋" }
            return c < 0.3 ? "你的\(side)大腿内侧" : "你的\(side)大腿"
        default: return c < 0.15 ? "你的腿根之间" : "你的\(side)膝盖"
        }
    }

    /// 上下来回了几次（feel.py 的 `(flips + 1) // 2 + 1`）：纵向换向超过 6pt 才算一次。
    static func verticalStrokes(_ samples: [TouchSample]) -> Int {
        var flips = 0, dir: CGFloat = 0, anchor = samples.first!.point.y
        for sample in samples.dropFirst() {
            let dy = sample.point.y - anchor
            if abs(dy) < 6 { continue }
            let d: CGFloat = dy > 0 ? 1 : -1
            if dir != 0, d != dir { flips += 1 }
            dir = d
            anchor = sample.point.y
        }
        return (flips + 1) / 2 + 1
    }

    static func bodyPlace(_ p: CGPoint, _ form: CGRect) -> String {
        let nx = (p.x - form.midX) / (form.width / 2), t = (p.y - form.minY) / form.height
        if abs(nx) > 1.08 || t < -0.04 || t > 1.04 { return "你身边的空处" }
        let side: String? = nx < -0.33 ? "右" : nx > 0.33 ? "左" : nil
        switch t {
        case ..<0.12: return side.map { "你\($0)边的头发" } ?? "你的头顶"
        case ..<0.30: return side.map { "你的\($0)脸颊" } ?? (t < 0.21 ? "你的额头" : "你的鼻尖")
        case ..<0.40: return side.map { "你的\($0)耳朵边" } ?? "你的下巴"
        case ..<0.50: return side.map { "你的\($0)边颈侧" } ?? "你的脖子"
        case ..<0.62: return side.map { "你的\($0)肩" } ?? "你的锁骨"
        case ..<0.82: return side.map { "你的\($0)臂" } ?? "你的胸口"
        default: return side.map { "你的\($0)手" } ?? "你的肚子"
        }
    }

    /// 离起点最远的那一点有多远（pt）：分「按」和「划」。
    static func reach(_ samples: [TouchSample]) -> CGFloat {
        let origin = samples.first!.point
        return samples.map { hypot($0.point.x - origin.x, $0.point.y - origin.y) }.max()!
    }
}

写进你发出的消息

要让模型真正「被摸到」，触摸就得直接写进你发出的那条消息里：翻译放在你打的字前面，合并成同一个文本块一起发送；一个字不打、只发送触摸也可以。模型收到消息时，触摸已经在里面了，一定能看到。

所以这件事要在前端里做，也就是你聊天时看到、用来打字的那个界面。手机上的前端有两种：

完整

原生 App

iOS 或安卓的原生 App：画面效果、按力度变化的震动、力度估算全都有，整个聊天页面都能跟着变形。

没有震动

网页 / PWA

画面效果和翻译都有，在单独的触摸层上；iPhone 的浏览器不支持网页震动，安卓只能控制震动时长。

/// 触感空间接进你自己的聊天前端，只需要这几样。
///
/// 1. 让你的聊天模型（或任何对象）遵守 `TouchChatHost`，创建一个 `TouchSpace(host:)`，自己留着它。
/// 2. 根视图加上 `.touchSpace(space)`：触感空间开着时盖住整块聊天页。
/// 3. 输入框旁边放 `TouchEntryButton(space: space)`：点它进入触感空间；攒着的触摸显示成「手 + 笔数」。
/// 4. 按发送时：`let touch = space.takeForSending()`，有的话排在正文前面、合成同一个文本块发出去。
///    `space.hasPending` 为真时，一个字不写也应该允许发送。
/// 5. 模型回复时调用 `space.replyDelta(新来的那段)`，结束时调用 `space.replyFinished(完整回复)`。
///    触感空间靠它重拍聊天页（回话出现在被摸的画面里），实时模式也靠它等模型说完再发。
/// 6. 聊天气泡里：`TouchPacket.split(用户消息)` 拆出触摸段，用 `TouchChip` 折成「手 + 笔数」，剩下的正文照常显示。

public protocol TouchChatHost: AnyObject {
    /// 模型是不是正在回复（实时模式下，回复期间的触摸先攒着）。
    var isReplying: Bool { get }
    /// 实时模式：立刻发出一条只带触摸的消息。`text` 是翻译好的 `<touch …>` 段。
    func sendTouchNow(_ text: String)
    /// 出错时报给你（截图失败、震动引擎起不来之类）。可以只打日志。
    func touchSpaceReport(_ source: String, _ message: String)
}

public extension TouchChatHost {

    }
}

public extension View {

    }

/// 触感空间：点输入区那只手进入的全屏空间。空间里就是整块聊天页本身——进空间前截一张图铺满，
/// 在手指下按两种「看法」之一变形（水纹 / 皮肤，`TouchLook`），不变暗。
///
/// 交互规则：摸完放进输入框，她还能打字：
/// - 在空间里 = 开着。顶上一枚胶囊：一只手（有没放进去的触摸时是实心）+ 两个效果图标 + ✓ / ✕。
/// - 摸完点 ✓：回到聊天，这一批留在输入框里（输入区那只手旁边一枚「手 + 笔数」的小标签），
///   跟她打的字一起、按发送时发出（宿主调用 `takeForSending()`）；一个字不写也能发。没摸过时那个钮是 ✕，只是回去。
/// - 小标签上的 × 或长按胶囊 →「清掉这一批」；点小标签回到空间接着摸，笔数接着加。
/// - 新建页一样能进；在新建页按发送就用这一批开新会话（与「第一句话」同一条路径）。
/// - 模型的回复：iOS 直接出现在聊天记录里（空间在单独一层窗口，回话一到就重拍聊天页，见 `TouchWindow.swift`）；
///   Mac 照旧以很淡的文字浮在空间里几秒。
/// - **实时**（胶囊里的「实时」开关，存 UserDefaults `touch.live`）：不用点 ✓，摸着摸着就自动发，
///   回话浮在空间里，她不用离开接着摸。节奏在调参面板里选：边摸边发（每隔 N 秒发一次，还按着的那一笔截到此刻、
///   下一次写「接着……」）或停手后发（停 N 秒才发）。模型还在说话时新的触摸先攒着，它说完再一起发，不打断、
///   不排一串。开着实时点 ✕ 回去：没发的立刻发。手底下的震动、画面照旧即时。

    public func open() {
        #if os(iOS)
        // 输入框正打着字的话，先把键盘收走（键盘在自己的窗口里，会盖在空间上面）。
        UIApplication.shared.sendAction(#selector(UIResponder.resignFirstResponder), to: nil, from: nil, for: nil)
        #else
        // Mac：输入框还握着键盘焦点的话，打的字会进被盖住的输入框，Esc 也被它吃掉（关不了空间）。
        NSApp.keyWindow?.makeFirstResponder(nil)
        #endif
        // 空间还没出现：此刻窗口里就是她看到的聊天页。
        do {
            snapshot = try TouchSnapshot.capture(in: hostObject)
        } catch {
            snapshot = nil
            report("touch", "进触感空间时没截到聊天页，这次不变形（照样能摸、能发）：\(error)")
        }
        haptics.prepare()
        isOpen = true
        // 进空间后宿主可能还在动版面：稍后再拍一次，空间里就是滑好的样子。
        refreshSnapshotSoon(after: 0.5)
    }

    #if os(iOS)
    private var hostObject: AnyObject? { hostWindow }

    /// 只有 iOS 拍得到（空间在另一层窗口）；Mac 空间盖在同一个窗口里，重拍会把空间自己拍进去，所以不拍、回话照旧浮在空间里。
    /// 调参面板开着不拍（Mac 同理；iOS 面板也在空间那一层，拍不进来，但省得面板挡着时白拍）。
    func refreshSnapshotSoon(after seconds: Double) {
        #if os(iOS)
        guard isOpen, refreshTask == nil else { return }
        refreshTask = Task { [weak self] in
            try? await Task.sleep(for: .seconds(seconds))
            guard let self, !Task.isCancelled else { return }
            self.refreshTask = nil
            guard self.isOpen else { return }
            do {
                self.snapshot = try TouchSnapshot.capture(in: self.hostObject)
                self.renderer?.wake()
            } catch {
                // 这一次没拍到：留着上一张，下一次回话再拍。
            }
        }
        #endif
    }

    func dropSnapshot() {
        snapshot = nil

    func select(_ look: TouchLook) {

        filter.reset(look)

    func canvasResized(_ size: CGSize) {

        store.form = CGRect(origin: .zero, size: size)
    }

    public func close() {

        filter.reset(look)
        haptics.strokeEnded()
        isOpen = false
        refreshTask?.cancel()
        refreshTask = nil
        snapshot = nil
        panelOpen = false
        replyFade?.cancel()
        replyVisible = false

        store.discard()
        stopLive()
    }

        stopLive()
        if live { liveAfterChange() }
    }

    func openPanelDroppingActive() {
        store.dropActive()
        filter.releaseAll()
        renderer?.wake()
        haptics.strokeEnded()
        panelOpen = true
    }

    // MARK: 手指（表面视图转来）

    func began(_ key: AnyHashable, _ sample: TouchSample, source: TouchPressureSource) {
        defer { liveAfterChange() }
        store.began(key, sample, source: source)
        filter.press(key, at: sample.point, time: sample.time)
        renderer?.wake()
        haptics.tap(sample.pressure)
    }

    func moved(_ key: AnyHashable, _ samples: [TouchSample]) {
        store.moved(key, samples)
        guard !samples.isEmpty else { return }
        // 每个合并采样都喂：水纹按走过的距离落滴，漏掉中间点会少落。
        var speed: Float = 0
        for sample in samples { speed = filter.drag(key, to: sample.point, time: sample.time) }
        haptics.stroke(speed: speed, pressure: samples.last!.pressure)
    }

    func ended(_ key: AnyHashable, at time: TimeInterval) {
        store.ended(key, at: time)
        haptics.release(filter.release(key))
        if !store.isTouching { haptics.strokeEnded() }
        liveAfterChange()
    }

    private var liveWhileTouching: Bool { tuning.value.liveWhileTouching }

    }

    /// 摸了 / 抬手了：按节奏排下一次发送。
    /// - 边摸边发：已经在数就不动（每 N 秒一拍，摸着不会把它推后）；没在数、又有东西可发，就开始数。
    /// - 停手后发：一碰就停住；所有手指离开才开始数。
    private func liveAfterChange() {
        guard live, isOpen, !liveWaiting else { return }
        if liveWhileTouching {
            if liveTask == nil, store.hasPending || store.isTouching { armLive() }
        } else {
            if store.isTouching {
                cancelLiveTimer()
            } else if store.hasPending {
                armLive()
            }
        }
    }

    private func armLive() {
        cancelLiveTimer()
        let seconds = liveSeconds
        liveRing = (Date(), seconds)
        liveTask = Task { [weak self] in
            do {
                try await Task.sleep(for: .seconds(seconds))
            } catch {
                return // 又摸了（停手后发）/ 关了 / 关掉实时 / 清掉了。
            }
            guard let self else { return }
            self.liveTask = nil
            self.liveRing = nil
            self.sendLive(force: false)
            self.liveAfterChange()
        }
    }

    /// 发这一批。模型还在说话：先不发，等它说完再一起发（`force` = 回聊天时，不等，进它的收件箱排队）。
    private func sendLive(force: Bool) {
        guard store.hasPending else { return }
        if dryRun {
            // 试摸：不往会话里发，把本来要发的那段写进日志（验收时看描述对不对）。
            if let packet = store.takePacket() {
                Self.liveLog.info("试摸，没发：\(packet.text, privacy: .public)")
            }
            haptics.sent()
            return
        }
        guard let host else {
            report("touch", "没有接聊天前端（TouchSpace.host），实时触摸发不出去（这一批还留着）")
            return
        }
        if host.isReplying, !force {
            // 模型还在说话：先攒着，宿主调用 `replyFinished` 时再一起发。
            liveWaiting = true
            return
        }
        liveWaiting = false
        guard let packet = store.takePacket() else { return }
        host.sendTouchNow(packet.text)
        haptics.sent()
        // 她的那条落进聊天记录：重拍一下，空间里看得到。
        refreshSnapshotSoon(after: 0.35)
    }

    private func sendIfReplyDone() {
        guard liveWaiting, let host, !host.isReplying else { return }
        liveWaiting = false
        sendLive(force: false)
        liveAfterChange()
    }

    private func cancelLiveTimer() {
        liveTask?.cancel()
        liveTask = nil
        liveRing = nil
    }

    private func stopLive() {
        cancelLiveTimer()
        liveWaiting = false
    }

    // MARK: 回复（宿主转来）

    /// 宿主在模型回复的过程中，每收到一段文字就调用一次（text 是新来的这一段）。
    public func replyDelta(_ text: String) {
        guard isOpen else { return }
        #if os(iOS)
        // iOS：回话就在聊天记录里，空间重拍聊天页就看得到。流式时最多每 0.4 秒拍一次。
        refreshSnapshotSoon(after: 0.4)
        #else
        if !replyStreaming {
            replyStreaming = true
            reply = ""
        }
        reply += text
        replyFade?.cancel()
        replyVisible = true
        #endif
    }

    /// 宿主在模型回复结束时调用（text 是完整的回复，可以传空字符串）。
    /// 实时模式下，模型说话期间攒着的触摸会在这时一起发出去。
    public func replyFinished(_ text: String = "") {
        defer { sendIfReplyDone() }
        guard isOpen else { return }
        #if os(iOS)
        // 落账后拍一次，再过一会儿补一次（Markdown 的行高可能是异步量的，第一次拍时版面可能还在动）。
        refreshTask?.cancel()
        refreshTask = nil
        refreshSnapshotSoon(after: 0.35)
        Task { [weak self] in
            try? await Task.sleep(for: .seconds(1.2))
            self?.refreshSnapshotSoon(after: 0)
        }
        #else
        replyStreaming = false
        if !text.isEmpty { reply = text }
        replyVisible = !reply.isEmpty
        fadeReplyLater()
        #endif
    }

    private func fadeReplyLater() {
        replyFade?.cancel()
        replyFade = Task { [weak self] in
            do {
                try await Task.sleep(for: Self.replyLinger)
            } catch {
                return // 新的回复又来了。
            }
            self?.replyVisible = false
        }
    }
}

/// 手感参数（调参面板的滑杆）。0…1 的旋钮。在真机上调好后点「复制当前参数」，
/// 把那串抄成新的出厂值（改下面的缺省值）。现在的出厂值是我们在真机上调出来的。
/// 两根：「触感强度」和「皮肤范围」。其余滤镜常数照网页草图，不开滑杆。
/// UserDefaults 里存着的 JSON 若多出别的键，解码时忽略，触感强度照旧读得回来。
struct TouchTuning: Codable, Equatable {
    /// 触感（震动）强度。
    var haptics = 0.53
    /// 皮肤效果的范围。0.5 = 基准（凹陷半径 34pt），0 = 一半，1 = 两倍；出厂 0.73 ≈ 1.38 倍（约 47pt）。
    var skinSize = 0.73

    /// 皮肤范围旋钮 → 倍数：2^((v − 0.5) × 2)，0.5…2。
    var skinSizeScale: Double { pow(2, (skinSize - 0.5) * 2) }

    /// 实时触摸的节奏：true = 边摸边发（每隔 `liveSeconds` 秒发一次，手指不用抬）；
    /// false = 停手后发（所有手指离开、`liveSeconds` 秒内没再摸才发）。
    /// 出厂是停手后发（边摸边每两秒发一包，读起来太零碎）。
    var liveWhileTouching = false
    /// 实时触摸的秒数：边摸边发时是间隔，停手后发时是停顿。0.3…3。
    var liveSeconds = 2.0
    static let liveSecondsRange: ClosedRange<Double> = 0.3...3

    /// 发给模型的描述里，位置用哪套说法：屏幕（你的正中间、你偏右上的地方）、上半身（你的额头、你的右肩）或下半身（你的小腹、你的左大腿）。
    var placeMap = TouchPlaceMap.screen

    static let factory = TouchTuning()

    init() {}

    /// 缺的键用出厂值（旧版本存的键少，合成的解码会整串报错、把调过的参数也丢掉）。
    init(from decoder: Decoder) throws {
        let c = try decoder.container(keyedBy: CodingKeys.self)
        haptics = try c.decodeIfPresent(Double.self, forKey: .haptics) ?? Self.factory.haptics
        skinSize = try c.decodeIfPresent(Double.self, forKey: .skinSize) ?? Self.factory.skinSize
        liveWhileTouching = try c.decodeIfPresent(Bool.self, forKey: .liveWhileTouching) ?? Self.factory.liveWhileTouching
        liveSeconds = try c.decodeIfPresent(Double.self, forKey: .liveSeconds) ?? Self.factory.liveSeconds
        placeMap = (try? c.decodeIfPresent(TouchPlaceMap.self, forKey: .placeMap)) ?? Self.factory.placeMap
    }

    /// 面板上的顺序、名字与导出用的字段名（同 Codable 的键）。
    static let knobs: [(label: String, name: String, key: WritableKeyPath<TouchTuning, Double>)] = [
        ("触感强度", "haptics", \.haptics),
        ("皮肤范围", "skinSize", \.skinSize),
    ]
}

/// 参数存 UserDefaults（键 `touch.tuning`，JSON）。
@MainActor
final class TouchTuningStore: ObservableObject {
    static let defaultsKey = "touch.tuning"

    @Published var value: TouchTuning {
        didSet { save() }
    }

    init(report: (String) -> Void) {
        guard let data = UserDefaults.standard.data(forKey: Self.defaultsKey) else {
            value = .factory
            return
        }
        do {
            value = try JSONDecoder().decode(TouchTuning.self, from: data)
        } catch {
            // 存的解不开 = 字段改过名。报告出来（附原文，好手抄回去），这次用出厂值。
            report("存着的手感参数解不开，这次用出厂值（\(error)）\n原文：\(String(decoding: data, as: UTF8.self))")
            value = .factory
        }
    }

    /// 「复制当前参数」复制的那一串（键排好序，两位小数）。
    var exportText: String {
        var fields = TouchTuning.knobs.map {
            "\"\($0.name)\": \(String(format: "%.2f", value[keyPath: $0.key]))"
        }
        fields.append("\"liveWhileTouching\": \(value.liveWhileTouching)")
        fields.append("\"liveSeconds\": \(String(format: "%.1f", value.liveSeconds))")
        fields.append("\"placeMap\": \"\(value.placeMap.rawValue)\"")
        return "touch.tuning {\(fields.joined(separator: ", "))}"
    }

    private func save() {
        // 只有 Double / Bool / 枚举字段的结构体，编码不会失败。
        UserDefaults.standard.set(try! JSONEncoder().encode(value), forKey: Self.defaultsKey)
    }
}

// SPDX-License-Identifier: PolyForm-Noncommercial-1.0.0
// 自己的前端：发送时把攒下的触摸翻译排在正文前面，合成同一个文本块（通用写法）
function buildMessage(draft, pendingTouch) {
  const parts = [];
  if (pendingTouch) parts.push(pendingTouch);   // <touch strokes="…"> … </touch>
  if (draft.trim()) parts.push(draft.trim());
  // 一定要是同一个文本块：气泡靠「正文以 <touch 开头」认出它
  return { role: 'user', content: [{ type: 'text', text: parts.join('\n\n') }] };
}

// 气泡里：把 <touch> 段折成「👆 笔数」，点开看全文；剩下的正文照常显示
function splitTouch(text) {
  const m = text.match(/^<touch strokes="(\d+)"[^>]*>\n([\s\S]*?)\n<\/touch>\s*/);
  if (!m) return { touch: null, strokes: 0, rest: text };
  return { touch: m[2], strokes: Number(m[1]), rest: text.slice(m[0].length) };
}

两种发送模式

两种都好用，可以在界面上放一个开关，随时切换。

  • 和你的话一起发：适合想一边触摸、一边对它说话的时候。摸完点一下确认，这批触摸放进输入框，显示成「👆 7」这样的小标签，你可以再打几句话，按发送时一起发出去。不会催你。
  • 停手两秒自动发：适合想让它实时感受到你的触摸的时候。停手两秒，这批触摸自动单独发送，模型的回复直接出现，你可以接着摸。模型还在回复时，新的触摸先攒着，等它说完再一起发，不会打断它，也不会排成一长串。我们也试过「边摸边每隔几秒发一次」，还按着的那一笔先翻译成「……还没松手」，下一次接着写「接着……」；但读起来比较零碎，最后还是选了停手后再发。

自动发送时，每发送一次，模型就会完整回复一次，触摸得越零碎，额度或 token 消耗得越快。

踩过的坑

  • 一直按着不动时没有新的采样，时长会算成 0：发送时把还按着的那一笔截到发送那一刻。
  • 画圈和在一条线上来回划，首尾都挨得近，要看是不是横竖都有一截才分得清。
  • 变形的面积宁小勿大：太大整片在晃，像在摸水面不像摸人。
  • 触感空间如果盖在聊天页同一层，再拍聊天页会把它自己拍进去；放到单独一层（iOS 的单独窗口）后，那一层拿不到 SwiftUI 的 scenePhase，要自己看 App 在不在前台，不然画布以为在后台、一帧都不画。
